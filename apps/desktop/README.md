# T19 — S1 主程序应用壳（Phase1 最小壳）

## 架构原则

### ADR-0037 目标与迁移期依赖

ADR-0037 已取代 ADR-0017/0025 中“由 S1 横向协调”的旧授权。目标态只允许 S1
使用页面状态、进度、导航结果和通知等呈现能力与共享展示类型；一次用户操作只转发给
一个功能模块。S1 不协调功能模块或基础模块，也不直接持有持久化、生成或导出实现。

**迁移期实际依赖**（仅记录现状，不是新增依赖的白名单或授权）:
- `slint` — UI 框架（官方默认 features：winit 后端 + femtovg/软件渲染器）
- `localization` (B6) — 全部文案经 `l10n.t()` 注入（ADR-0005 文本外置铁律）
- `global-settings` (F1) — 现有首次运行判定 + 老用户着陆校区，待由 F1 返回单一着陆结果
- `data-persistence` (B2) — 现有启动路径直接打开数据库，属于待迁出职责
- `anyhow` — 错误链路

不得扩展上述迁移期直接依赖。业务实现依赖应位于对应功能模块；S1 只消费呈现接口。

### 薄壳原则

1. **零业务逻辑**: Slint 声明层只做展示和事件分发
2. **ViewModel 绑定**: 向各功能模块索取 ViewModel 状态和操作回调（全量接线在 T19B）
3. **单模块转发**: 一次用户操作只转发给一个功能模块；S1 不承担跨模块业务协调
4. **文案外置**: 所有文本走 B6 国际化（`l10n.t("xxx")` + zh-CN.json）

## 目录结构

```
    ├── runtime.rs             # 现有首开协调 + 主窗口装配（协调职责待迁出）
    └── main.rs                # campus-tool-dev 入口
```

## 首开着陆判定（迁移前现状，`runtime::landing_decision`）

1. 首次运行（或本地库尚不可用）→ 设置向导去向
2. 老用户且 F1 记有上次校区 → 直达该校区去向
3. 否则（含上次校区已被删，F1 兜底为 `None`）→ 校区选择去向

上述行为由工单 01 的用户可观察行为基线固定，但现有 S1 直接读取数据库并组合 F1
结果不再是目标架构授权。ADR-0037 的目标是由 F1 返回单一着陆结果，S1 只负责呈现；
迁移必须由后续工单完成，本工单不改变产品行为。

## 开发版快捷方式

由 `cargo xtask dev-shortcut` 承担（ADR-0014）：build.rs 运行于链接之前
拿不到 exe，不能在 build.rs 里做快捷方式。

## ADR-0037 迁移债务（后续工单）

1. 将 S1 直接持有的持久化、采集转换、几何、生成与导出实现迁入对应功能模块
2. 由功能模块返回页面状态、进度、导航结果和通知等呈现数据
3. 将每个用户操作收敛为向单一功能模块的一次转发
4. 在职责迁移完成后收紧 `Cargo.toml` 与架构检查
