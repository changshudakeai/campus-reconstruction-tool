# 08 — 迁移评审工作台

**What to build:** 让评审入口完整管理候选状态、批量操作、确认要求和封账条件，S1 只显示工作台页面并转交用户操作。

**Blocked by:** 02 — 建立新呈现入口并保留旧通道.

**Status:** ready-for-agent

- [ ] 待定、保留、剔除三态及其显示符合现有决定。
- [ ] 单项和批量操作由评审入口返回完整的新页面状态或确认要求。
- [ ] S1 不自行修改候选状态、不计算批量结果，也不持有另一份评审业务副本。
- [ ] 建筑重叠、明确建筑组成关系和跨类别明显位置冲突按 ADR-0033～0035 呈现。
- [ ] 道路连通性不检查、不提醒、不报告，也不自动修正。
- [ ] 单个候选问题不会阻断整个评审工作台。
- [ ] 评审故障时已经保存的采集数据与其他安全页面保持可用。
- [ ] 封账条件由评审入口返回，S1 不自行判断是否可以导出。
- [ ] 评审工作台的现有用户可观察行为基线全部通过。
