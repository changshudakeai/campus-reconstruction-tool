# 09 — 迁移导出完整流程

**What to build:** 让一次“开始导出”由导出入口完整完成生成、版本核对、用料统计、Sponge 文件和写出，S1 只显示确认、进度和最终结果。

**Blocked by:** 02 — 建立新呈现入口并保留旧通道.

**Status:** ready-for-agent

- [ ] S1 只向导出入口发出一次完整导出请求，不直接访问 Manifest 或生成引擎。
- [ ] 导出入口内部协调评审封账、生成方块模型、MC 版本校验、用料统计、Sponge 文件和最终写出。
- [ ] 导出确认、取消、处理中、成功和失败均返回完整可呈现结果。
- [ ] 导出较长计算在后台执行，窗口立即显示进度且保持响应。
- [ ] 默认导出位置不可用时按已确认规则提供选择其他位置或取消，不静默改写全局默认。
- [ ] 导出失败不损坏已保存的边界、朝向、采集和评审数据。
- [ ] 较早导出任务的过期结果不会覆盖较新的操作状态。
- [ ] 成功或失败产生正确通知事实，故障时可以从通知中心导出相关故障资料。
- [ ] 导出的现有用户可观察行为和成品结果基线全部通过。
