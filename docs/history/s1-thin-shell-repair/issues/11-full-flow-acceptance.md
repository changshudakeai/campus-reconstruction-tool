# 11 — 完整流程回归验收

**What to build:** 从首次启动到最终导出完整验收重构后的 V2，证明用户可见行为保持不变、界面不冻结、故障不会互相拖累，并确认 S1 已成为真正的呈现薄壳。

**Blocked by:** 10 — 删除旧总接线并锁死架构护栏.

**Status:** ready-for-agent

- [ ] 首次设置、校区搜索、最近使用记录、方案列表和进入方案的完整路径通过。
- [ ] 五步顶部始终显示校区名和方案名，边界、朝向、采集、评审和导出完整路径通过。
- [ ] 设置保存、联网测试、方案恢复、采集和导出等成功操作均显示正确短暂提示或通知。
- [ ] 正式数据读取或保存失败时没有静默内存后备，并可重试或导出故障资料。
- [ ] 高德地图、覆盖率检查或导出单独失败时，其他安全功能仍可使用。
- [ ] 所有联网和耗时操作在后台执行，页面立即显示状态，窗口无冻结。
- [ ] 页面离开、任务取消、后台继续和需要确认的行为符合功能模块返回的决定。
- [ ] 用户可观察行为与迁移前基线一致，发现的既有产品偏差已单独记录而未混入结构修复。
- [ ] 依赖、规模、公开接口、测试和完整工作区门禁全部通过。
- [ ] 验收记录明确说明 S1 只承担页面呈现、临时页面状态和结果显示，不再承担业务协调。
