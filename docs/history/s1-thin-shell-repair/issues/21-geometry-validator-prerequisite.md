**What to build:** 为 ADR-0032 已确认的候选对象几何隔离建立 `geometry-validator`（B14）模块与最小接口，使 A1 `collection-flow` 可以如实统计自动修复、剔除和保留的对象，而不把规则塞进 S1。

**Blocked by:** 无。

**Status:** ready-for-agent

- [ ] 在 workspace 中立户 B14 `geometry-validator`，依赖方向符合 ADR-0017；S1 不直接依赖 B14。
- [ ] 只检查采集候选对象，不接管 B5 的方案边界点数、面积和自相交检查。
