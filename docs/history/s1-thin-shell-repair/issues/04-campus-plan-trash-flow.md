# 04 — 迁移校区、方案、最近记录与回收站

**What to build:** 让校区搜索、最近使用记录、方案列表和回收站通过一个完整的方案管理入口工作，S1 只转交操作并显示返回的页面状态与通知。

**Blocked by:** 02 — 建立新呈现入口并保留旧通道.

**Status:** implemented（2026-08-01 提交 [S1-04] 并合并 PR #7；待负责人验收）

- [x] 校区搜索只在点击“搜索”或按回车时开始，输入期间不自动搜索。
- [x] 搜索结果与最近使用记录按已确认规则切换，没有记录时直接显示搜索框。
- [x] 选择重复校区时直接进入原校区方案页面，并返回“该校区已添加，已为你切换”的通知事实。
- [x] 最近使用记录显示校区名称和地址，最近进入的排最前，右侧小叉立即移除记录且不弹确认窗口。
- [x] 创建、重命名、复制、删除和恢复方案均由方案管理入口完成。
- [x] 回收站恢复、永久删除和清空后的停留位置与短暂提示符合现有决定。
- [x] 方案管理入口持有正式数据规则，S1 不直接读写数据库或保存校区、方案业务副本。
- [x] 单个方案操作失败时方案页面保持可用并显示正确错误，不拖垮其他功能。
- [x] 校区、方案和回收站的现有用户可观察行为基线全部通过。
