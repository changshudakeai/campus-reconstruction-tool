# 07 — 迁移采集与覆盖率检查

**What to build:** 建立 A1 `collection-flow`，完整管理数据源、分类、持久化、B14 候选几何处理、增量刷新、进度和采集后的覆盖率检查，S1 只显示处理状态、变化结果和必要提醒。

**Blocked by:** 02 — 建立新呈现入口并保留旧通道；21 — B14 候选几何验证能力立户。

**Status:** ready-for-agent

- [ ] 点击开始采集后立即返回处理中状态，联网和计算在后台执行，窗口保持响应。
- [ ] 一次“开始采集”只跨越 A1 完整接口；S1 不在运行期先调用采集再调用覆盖体检。
- [ ] 采集入口内部协调数据源、六类别分类、正式保存和增量刷新，S1 不直接调用这些底层步骤。
- [ ] 重新采集继续按“变化优先、全量可查”的已确认行为呈现。
- [ ] A1 在自己的 seam 后调用 F4/F7，并直接使用 B2/B14；F4/F7 保持 Cargo 横向零依赖，S1 组合根只注入 A1。
- [ ] 单个无效候选从候选列表剔除，不阻断整次采集。
- [ ] 一个数据源或覆盖率检查失败时，只暂停受影响能力；已经成功保存的数据仍可查看。
- [ ] 后发采集任务的状态不会被较早任务的过期结果覆盖。
- [ ] 离开采集页面时由采集入口返回可以离开、后台继续或需要确认的决定。
- [ ] 成功、失败和需要用户处理的结果生成正确通知事实。
- [ ] 采集与覆盖率检查的现有用户可观察行为基线全部通过。
