# 02 — 建立新呈现入口并保留旧通道

**What to build:** 为 S1 建立按功能划分的小而完整的呈现入口，使页面可以通过模拟功能结果完成显示和交互；旧接线暂时保留，软件在迁移期间始终可运行。

**Blocked by:** 01 — 固定书面规则与现有行为基线.

**Status:** implemented（2026-07-30 提交 [S1-02]；CI 无 GPU 修复随 PR #3 合并，2026-07-31；待负责人验收）

- [ ] 首次启动、设置、校区与方案、采集、评审、覆盖率检查、导出和通知分别有明确的呈现入口。
- [ ] 每个入口可以返回完整页面状态、操作结果、处理中状态、导航决定或通知事实，不要求 S1 多轮拼装。
- [ ] 测试可以用模拟入口返回成功、失败、处理中和需要确认等结果，并验证 S1 的显示。
- [ ] 生产入口与模拟入口通过同一接口工作，调用者不需要知道内部实现。
- [ ] 不建立掌握所有业务细节的全局超级协调器。
- [ ] 旧接线与新入口可以在迁移期间并存，现有完整行为基线保持通过。
- [ ] 本工单不向 S1 新增业务判断、正式数据副本或底层业务依赖。
