# 01 — 固定书面规则与现有行为基线

**What to build:** 把已经确认的 S1 呈现薄壳规则、V2 不提供高德离线地图的范围，以及当前用户可观察行为整理成一致且可验证的基线，后续结构迁移不得悄悄改变这些行为。

**Blocked by:** None — can start immediately.

**Status:** implemented（2026-07-30 提交 [S1-01] 系列；待负责人验收）

- [ ] ADR 索引、模块决策索引和“薄壳”术语定义均引用最新决定，旧 ADR 不再授权 S1 直接协调持久化、生成或导出实现。
- [ ] 依赖规则明确区分 S1 可使用的呈现能力与禁止接触的业务实现。
- [ ] 为启动、设置、校区与方案、五步流程、采集、评审和导出建立当前用户可观察行为基线。
- [ ] 基线覆盖成功、失败、处理中和需要确认四类结果。
- [ ] 行为基线只观察页面、状态、通知和导航结果，不固定内部函数或数据结构。
- [ ] V2 不提供高德离线地图、不抓取或缓存高德地图内容的范围在地图相关决策中可追溯。
- [ ] 文档和基线检查通过，未修改任何已确认的产品行为。
