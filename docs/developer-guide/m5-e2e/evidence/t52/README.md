## 最终验收记录（2026-08-20，产品负责人确认通过）

1. **底座形状**：按真实边界多边形裁剪，不再铺满外接矩形。真实校区负载
   `659,928` 方块，各 z 行宽度 6–716 不等（如 z=1 行 x 253–258、z=571 行
   x 98–806），边界形状可见。
2. **表层材质**：底座统一 `minecraft:grass_block`（草方块），不再使用砖纹；
   建筑地基/道路/水面/植被保持不变。
3. **纹理精细度**：图集 504×504（16×16 内容 + 1px padding），
   LinearFilter + LinearMipmapLinearFilter + mipmap，远景无噪点/闪烁；
   半球光 0.9 + 平行光 0.95，观感明亮柔和；定位到建筑后砖墙/窗户/屋顶/
   栅栏纹理清晰。
4. **帧率**：preview_stats 稳态 160–165 fps（目标 30–60）；分块并行构建
   168 块 / 56,196 quads（Node 全链路同负载验证）。
5. **交互与衔接**：进入第五步不自动生成；点“生成 3D 预览”后生成；旋转/
   缩放/复位可用；候选卡片“定位到 3D 预览”飞行取景+高亮；导出完成后同
   区域继续显示预览+导出结果状态；第一/二/三/四步地图现场不变。
6. **失败处理**：预览失败给出明确错误提示且不阻塞导出；预览页切走离屏
   保留（零重建），创建失败自动退避重试（300/600/1200ms）。
7. **与 .schem 一致性**：预览与导出共用 B18 `BlockModel`；边界直出/增强
   导出均与预览同源，块级一致性由 `export-console`/`export-flow` 契约测试
   覆盖（RLE 展开 ↔ VoxelModel 逐块一致）。

## 早期走查操作步骤与观察（2026-08-19，留痕）

## 操作步骤与观察

1. 进入第五步：抽屉出现显眼的「生成 3D 预览」按钮；预览状态为空，预览页
   不加载任何生成数据——`进入第五步不自动生成`。
   - 证据：`step5-restored-no-autogen.png`（重启恢复第五步后同样不自动生成）。
2. 点击「生成 3D 预览」：后台生成，抽屉显示
   「3D 预览已生成：918232 个方块，与导出内容一致。」
   - 证据：`step5-preview-generated.png`。
3. 旋转/缩放/复位：左键拖拽旋转、滚轮缩放、抽屉「复位视角/放大/缩小」按钮。
   - 证据：`step5-preview-rotated.png`、`step5-preview-zoomed.png`、
     `step5-preview-reset.png`。
4. 帧率：预览页每 2 秒回传 `preview_stats`，稳态 160–165 fps（目标 30–60）；
   918,232 方块经同色面贪婪合并后仅 6 个可见面四边形。
   - 日志摘录（`t52-walkthrough.log`）：
     `preview_loaded {"blocks":918232,"quads":6,"simplified":false}`
     `preview_stats {"fps":165,"blocks":918232,"quads":6}`
5. 导出衔接（基础导出）：导出完成显示「导出完成」与
   「1064×1×863」尺寸，同区域继续显示 3D 预览，预览状态保留。
   - 证据：`step5-after-export.png`；`59d53f43-…schem` 基础版 1162 字节。
6. 超大方案自动简化并提示：增强预览（基础场地 + 保留候选 3 项）包围盒达
   1285 万格，弹出「3D 预览已简化——方案较大，预览已自动简化渲染；方块数据
   与导出内容一致。」
7. 预览失败不阻塞导出：在真实 WebView2 快速重建时出现一次性创建失败
   （`HRESULT 0x80070057`），界面给出「3D 预览生成失败。可以继续导出，导出
   流程不受影响。」错误弹窗；导出随后照常完成。
8. 增强导出块级一致（早期版本）：预览「974121 个方块」= 导出的增强 `.schem`
   非空气方块数 974,121，逐块解码（Python NBT）：
