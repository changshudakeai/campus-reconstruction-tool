# ADR-0035：不同类别的包含关系——正常包含不提醒，明显位置冲突才提醒

## 状态

已接受（2026-07-29，产品负责人确认）

## 背景

校园地图中，大面积绿化区域包围教学楼、道路、球场或池塘是常见且合理的情况。仅因为一个对象位于另一个区域内部就提示问题，会产生大量无意义提醒。

但如果两个不同类别的对象会在实际生成中明显占据同一位置，例如树木、水面或道路落进建筑墙体，则需要让用户注意。软件仍不能仅凭这一关系安全决定删除哪一个对象。

## 决定

- 不同类别对象之间只有包含关系时，不标记为疑点，也不弹出提醒；
- 各对象仍按自己的类别独立进入评审，保留各自的原始资料和来源；
- 只有会在实际生成中明显占据同一位置的冲突才标记疑点，例如树木、水面或道路落进建筑墙体；
- 用户查看其中一个冲突对象时，地图同时高亮所有相关对象并说明“与另一对象位置冲突”；
- B15 不自动删除、裁切、移动或合并这些对象，用户仍按三态评审决定去留。

## 后果

- 绿地包围建筑、道路或球场等正常校园布局不会制造提醒噪声；
- 真正可能影响生成结果的位置冲突仍对用户透明；
- 软件不猜测哪份资料更正确，不擅自改变采集结果；
- 冲突判断的内部计算方式由实施阶段依据生成规则确定，不要求产品负责人选择技术阈值。
