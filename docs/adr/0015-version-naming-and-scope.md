# ADR-0015：版本命名与范围——v2.0.0 不包含单栋精修

## 状态

已接受（2026-07-25，产品负责人确认）；核心流程和必选步骤于 2026-08-01 由 ADR-0041 修订。

## 背景

v1.x 存在多个子版本（v1、v1.1），而当前重写项目需要明确的版本断点，避免命名混乱。同时，用户反馈"单栋精修模式"在当前阶段并非核心需求，建议延后实现。

## 决定

### 版本号规则

- **主版本（Major）**：重大重构或破坏性变更时递增。V2 重写项目从 **v2.0.0** 开始；
- **次版本（Minor）**：新增向后兼容功能时递增（如 v2.1.0、v2.2.0）；
- **修订号（Patch）**：修复 bug 或不影响行为的改动时递增（如 v2.0.1、v2.0.2）。

示例：
- v2.0.0：V2 首次正式发布，包含边界基础导出，以及可选的自定义朝向、候选采集、候选评审和增强导出；
- v2.1.0：新增方案列表优化、导出细节增强等功能；
- v2.0.1：仅修复 bug，不改功能。

### 范围定义（v2.0.0 包含/不包含）

#### ✅ 本期纳入（v2.0.0）

- **唯一必选步骤**：确认方案边界；未设置自定义朝向时默认地图正北；
- **可选采集**：建筑/道路/水域/植被/体育/其他（六类互斥分类）；
- **评审交互**：拉回数据后的过审、剔除、标记为"其他"；
- **最小导出**：foundation_manifest.json + 地基方块包；
- **开发版入口**：桌面快捷方式"校园复刻工具 - 开发版"；
- **全局设置页**：语言、游戏版本（ADR-0004）。

#### ❌ 本期排除（延后到未来版本）

- **单栋精修模式**：包括照片识别、立面规则编辑器、3D 精细预览等高级编辑能力；
- **自动更新机制**：v2.0.0 暂不自带"一键更新检查"，仍通过构建脚本覆盖；
- **多校区项目管理界面优化**：仅保留基础列表，不做高级看板视图。

### 原因

- **专注核心体验**：先确保“方案边界→基础导出”稳定可用，再补齐可选候选增强流程；
- **降低上线风险**：单栋精修涉及复杂交互与渲染逻辑，延后可减少初期缺陷率；
- **版本标识清晰**：用 v2.0.0 明确标示这是一次彻底重写，区别于 v1.x 的增量迭代。

## 后果

- v1.1 系列继续维护（如需要），但不再新增功能；V2 作为独立大版本推进；
- 未来若将"单栋精修"补入，将作为 v2.1.0 或更高版本的标志性功能；
- 用户可预期 v2.0.0 是一个"精简但完整"的首发版本，而非 Feature-complete 的最终形态。
