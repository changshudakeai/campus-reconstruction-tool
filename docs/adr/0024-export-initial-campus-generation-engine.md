# ADR-0024：导出成品——Arnis 式完整初始校园 + 生成引擎独立成模块

## 状态

已接受（2026-07-25，产品负责人确认）；最小导出前置和默认朝向于 2026-08-01 被 ADR-0041 修订。本决策继续定义导出成品，并修订 ADR-0017 模块目录（新增 B18，29 → 30 模块）。

## 背景

原话题 D（生成与导出细节）访谈。产品负责人明确纠正了"地基 = 平面底图"的理解：地基模式的成品应参考 [Arnis](https://github.com/louis-e/arnis) 的做法——根据框选区域生成质量较高的初始校园，而非只拍轮廓。v1.x 已移植 Arnis 的建筑生成规则（见 `New branch/docs/arnis-rule-lineage.md`：height 优先于 levels、levels×4+2 估高、屋顶形状规则、学校立面预设），血统现成。

## 决定

### 一、成品定义：完整初始校园（升级 ADR-0012 的"地基"含义）

导出物为**一个 `.schem` 文件**，内容包含（按评审保留的数据生成）：

- **初始建筑**：按 Arnis 规则自动起楼——有墙、有窗、有屋顶；高度按数据源信息（有 height 标注按标注，无则按"层数 × 4 + 2"估算）；定位为"像模像样的初稿楼"，照片级精品属未来精细建筑模式；
- **初始道路**（铺面、走线）、**初始水体**（水面）、**初始植被**（树木绿地）、**初始体育场地**（跑道划线、球场图案）；
- **"其他"类**按标签家族规则生成（如铁路 → 铁轨），规则逐步补齐（ADR-0011）。

跳过/未保留的类别不出现；最小路径仅需方案边界并导出平整空地，未设置自定义朝向时默认地图正北；manifest 如实记录包含/缺失类别（ADR-0041）。

### 二、导出格式：仅 `.schem`

复用 v1.x Sponge 导出引擎（ADR-0003）。**不做 MC 存档世界生成**（产品负责人明确否决：存档不方便；不列未来增强，要做须重新提案）。

### 三、地形：平地 + 高度扩展位

v2.0.0 将校园铺在同一水平面；数据结构为"高度"预留扩展位，将来做真实起伏无须翻修。真实起伏（需引入高程数据源）不入 v2.0.0（ADR-0015 精简首发）。

### 四、用料表：集中配置 + MC 版本强绑定

- "哪类对象用什么方块"集中于**用料配置表**，禁止散落写死（与色卡、动效表、标签映射表同族）；
- **用料表与 MC 版本强绑定**：只准使用全局设置（ADR-0004）所选 MC 版本中真实存在的方块，杜绝"新方块进老图纸"导致的空气/紫黑块事故；每个受支持版本各有一张核对过的表（或主表 + 版本降级替换规则，实现细节由实施决定）；
- 默认用料沿用 Arnis / v1.x 规则；实际生成效果由产品负责人在开发版中验收，与动画舞步同一次审核节奏（ADR-0023 模式）。

### 五、不做导入指引

**不教玩家如何把 `.schem` 导入游戏**——不附说明文档、不加指引按钮（产品负责人明确划界：这不属于本产品）。

### 六、数据粮仓（衔接未来精细建筑模式）

采集爬回的建筑原始信息（轮廓、标签、楼层/高度、名称等）**全部持久化入项目数据库，评审与导出之后均不删除**——它们是未来精细建筑模式的加工原料。v2.0.0 仅交付地基模式（ADR-0015 排除清单不变）。

### 七、新模块 B18：初始校园生成引擎（修订 ADR-0017）

现有模块无人认领"数据 → 方块模型"这段职责（B4 是打印机、B5 是丈量员、F9 是前台），故新立：

- **B18 `generation-engine`（基础模块）**：输入评审保留的数据，输出方块模型；承载全部生成规则（Arnis 建筑规则、道路/水体/植被/体育/其他生成规则）与用料配置表；
- 流水线：**评审保留数据 → B18 生成引擎 → B4 Sponge 导出（.schem 落盘）→ F9 导出控制台（打包 + manifest + 进度）**；
- 复用来源：v1.x `arnis-core` crate 迁入作地基；
- 模块目录 29 → **30**（基础模块 16 → 17）。

## 后果

- "地基"一词在全部文档中统一指"完整初始校园"，不再是平面底图；
- 用料表按版本核对是持续维护义务：每支持一个新 MC 版本，先补核对一张用料表；
- 生成规则与文件格式分居（B18/B4），变化节奏不同的两件事互不牵连，生成规则可脱离文件 IO 独立测试；
- 建筑原始数据不删的存储成本由 SQLite 承担（ADR-0002），schema 设计须包含原始观测表；
- 导入指引明确出界，相关文案、帮助页均不立项。
