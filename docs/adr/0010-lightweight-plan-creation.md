# ADR-0010：方案轻创建——起名即建立，边界是方案内第一个任务

## 状态

已接受（2026-07-25，产品负责人确认）

## 背景

需要确定用户在方案列表页点击"新建方案"后的交互编排。候选：

1. 轻创建：输入方案名即建立方案，画边界作为进入方案后的第一个任务；
2. 重创建：创建向导内强制完成起名 + 画边界，全部完成才算创建成功——被否决，因为画边界是重操作（缩放地图、逐点圈选），中途放弃会留下"创建了一半"的尴尬状态，且不支持"先建多个方案、以后慢慢做"的用法。

## 决定

- 点击"新建方案"弹出轻量对话框：仅输入方案名（预填可修改的默认名，如"方案 1"）；
- 确认后方案立即建立并进入方案工作区；
- 工作区将"确定复刻范围（画边界）"作为第一个任务呈现，支持从头画或一键复制本校区其他方案的边界（见 ADR-0007）；
- 未画边界的方案在方案列表中如实显示进度状态（如"尚未确定范围"），不视为异常；
- 中途退出不丢数据，由自动保存兜底。

## 后果

- 创建零门槛，与"一次只给用户一个当前任务"的工作区原则衔接自然。
- 方案列表的进度展示需要能表达"尚未确定范围"这一最早期状态。
- 方案名唯一性校验范围：同一校区内方案名不得重复（跨校区可重名）。
