# ADR-0040：原始观测与评审候选分层，并以候选资格控制评审和导出

## 状态

已接受（2026-08-01，按产品负责人“先修文档规则、遵守 ADR-0037、再实施代码”的指示落档）。本决策补充 ADR-0013/0016/0024/0030/0032/0039，解决 F4、B2、B14、F5 与 F9 之间缺少候选几何和可见性契约的问题。

## 背景

原始观测是必须永久保留的来源证据，评审候选则必须能被地图显示、人工判断并安全进入生成。两者不是同一种数据。现有接口把全部 `raw_observations` 直接变成 F5 候选，同时 F4 的高德来源只有 POI 点位，B14 的首版接口却只接受面环。如果继续把三者视为一物，要么会把点位全部误判为“有效点不足”，要么只能凭空给 POI 补造建筑轮廓；前者让评审无数据，后者违反“不猜测真实形状”和数据可追溯原则。

## 决定

### 一、建立两层数据模型

- **原始观测**是数据粮仓中的来源证据。数据源返回的标识、标签、属性、原始载荷和原始几何（若有）均按来源原样保留；点位、坏形状、未知标签和本次不能生成的对象也要入库，不因候选资格而删除。
- **评审候选**是从原始观测派生的、可重建的方案级投影。每条投影必须有稳定候选标识、采集批次、来源观测引用、数据源标识、六类别、展示属性、规范化几何和验证记录；不得用“类别 + 实体 ID”丢失多来源或多几何分片的来源关系。
- 候选投影由 B2 持久化，但不是新的数据粮仓。它可以在规则升级或重新采集后重建；原始观测仍是唯一不可删除的来源事实。

### 二、F4 必须交付带几何语义的采集批次

F4 的完整采集结果不能只有对象 ID、标签和任意 JSON。数据源若提供几何，F4 必须保留其 `Point`、`LineString`、`Polygon` 等形状种类与坐标，并在 B13 归类后形成候选草稿；数据源未提供可用几何时，仍形成原始观测，但不得伪造候选形状。

高德地点搜索返回的 POI 点位可以作为名称、位置和来源证据保存，但一个建筑 POI 点不等于建筑轮廓。除非后续已有明确接受该类别与形状组合的生成规则，否则点位不得用固定半径、包围盒或任意模板扩成面，也不得以“测试方便”为由算作可评审建筑。M3 的“拉回十来栋楼”必须由真实提供建筑轮廓的数据源或明确标注的几何夹具验收；夹具只能用于自动化测试，不能冒充生产联网能力。

### 三、B14 按形状种类验证，不把所有对象当面环

B14 的公开接口必须表达形状种类，并逐对象返回结构化结果：

- 点：坐标必须有限且在允许范围内；
- 线：至少有两个不同的有效点，不得含零长度连续段；
- 面：至少三个不同的有效点、闭合后面积非零且不自相交；
- 只有结果唯一且不改变外观的修复可以自动执行，并记录为“已修复”；无法安全处理、缺少所需形状或类别与形状不受当前规则支持时记录为“已隔离”。

“已修复”仍具有评审资格；“已隔离”不具有评审资格。单项隔离不阻断同批其他对象，原因和数量进入采集报告。B14 不负责方案边界，也不凭标签推测或创造几何。

### 四、候选资格是评审与导出的唯一入口闸门

候选处理记录只有两种资格：

- **可评审（Reviewable）**：有通过验证或唯一修复后的规范化几何，可进入 F5；
- **已隔离（Isolated）**：缺少可用形状、形状不合法或当前不支持，保留原始观测和原因，但不进入 F5/F9。

B2 必须提供专门的“列出可评审候选”接口。F5 不得再遍历全部原始观测并自行构造候选；F9 也不得查询原始观测、重复解释 B14 结果或绕过候选资格。存在候选时，F9 只接收 F5 封账后状态为“保留”的稳定候选标识，生成阶段据此读取同一份规范化候选投影。空候选集合按 ADR-0041 是合法的基础导出输入，不需要为了导出而伪造候选或评审记录。

重新采集时，ADR-0030 的“本次未找到”对象保留上一份已验证候选投影，标记“本次未找到”并把评审状态重置为“待定”；用户重新决定为“保留”前不导出。如果本次返回的形状变为不可用，则当前候选改为“已隔离”，旧评审决定不得让它继续导出。

### 五、A1 只发布完整候选批次

A1 `collection-flow` 在自己的接口后完成：调用 F4 取得采集批次、保存原始观测、调用 B14 处理候选草稿、让 B2 原子发布完整候选投影，再把原始数量、可评审数量、自动修复数量、隔离数量和分类汇总交给 F7。S1 仍只调用 A1 一次并显示结果。

原始观测保存成功但候选投影未完整发布时，原始证据不得回滚删除；该批次不得解锁评审，也不得覆盖上一份完整可用的候选投影。用户收到明确失败结果，后续可以重试候选处理。只有候选投影和采集报告均完成后，A1 才返回“采集完成并解锁评审”。

## 交付切分

本 ADR 定义从采集到导出的长期数据不变量，不表示所有受影响模块都必须在 M3 一次实现。M3 只负责让采集结果能够安全交给下一步评审，实施范围固定为：F4 来源几何批次、B14 形状验证、B2 候选投影与资格、F5 的最小进台读取接缝、A1 `collection-flow`，以及把现有采集编排从 S1 迁出。这里的 F5 工作只包含“从 B2 读取 Reviewable 候选”，不包含 T19B-7/M4 的评审页面和交互开发。

F9 的规则从本 ADR 接受之日起生效，但 F9 的实际身份模型迁移、封账和导出接线归 T19B-8/M5，不是 M3 的前置、实现范围或完成门禁。M3 只需由 B2 建好后续可读取稳定候选标识和规范化投影的公开能力，不得为了提前适配 F9 扩大采集工单。F1 与本 ADR 的 M3 实施范围无关。

## 拒绝的方案

- F5 继续把每条原始观测直接当候选：绕过 B14，无法保证问题对象不进评审/导出。
- 在 `raw_observations` 上增加一个松散布尔值并让各模块自行解释：会把来源事实和派生资格混在一起，并在 F5/F9 复制规则。
- 给高德 POI 自动画固定大小建筑：形状没有来源证据，生成结果不可追溯。
- A1 只负责调用顺序，不拥有完整批次发布语义：失败时会留下“原始已更新、候选半更新、评审却已解锁”的半截状态。

## 后果

B2 需要新增候选投影、采集批次和资格查询契约；F4 需要返回可追溯的几何草稿；B14 需要从首版单一面环接口扩展为形状感知验证；F5 必须改从候选投影进台；F9 在后续 M5 中只消费封账后的可评审候选。截至 2026-08-01，`880942a`/`99d95a7` 已补齐 B14 基线与点线面接口，`c080c26` 已建立 B2 候选投影持久化，`6d35130` 已建立 F4 来源几何批次但仍需补齐验收测试与全量门禁；M3 剩余范围以本节“交付切分”为准。
