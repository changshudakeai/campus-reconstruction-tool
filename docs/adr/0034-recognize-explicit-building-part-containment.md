# ADR-0034：明确的建筑组成关系——作为正常结构处理

## 状态

已接受（2026-07-29，产品负责人确认）

## 背景

地图资料可能同时提供整栋建筑的外轮廓，以及内部主楼、楼翼或不同高度楼体的局部轮廓。若资料已经明确说明小轮廓属于大建筑的一部分，这种包含关系代表正常建筑结构，不应被当作可疑重叠反复要求用户处理。

如果资料没有说明两者的从属关系，软件仍无法安全判断它们是否属于同一栋楼，应继续按 ADR-0033 的普通重叠疑点处理。

## 决定

- 当来源资料明确说明小轮廓是大建筑的组成部分时，B15 将其识别为正常建筑关系，不标记为错误或重叠疑点；
- 评审详情显示“小轮廓属于该建筑的一部分”，让用户可以了解关系；
- 大轮廓与组成部分的原始资料和来源信息全部保留；
- 生成时把它们作为同一组建筑处理，避免把明确的组成部分误当作另一栋独立建筑；
- 来源资料没有明确说明从属关系时禁止猜测，按 ADR-0033 的普通建筑重叠规则提醒用户。

## 后果

- 主楼、楼翼和不同高度楼体不会制造大量无意义提醒；
- 明确的数据关系可直接被软件利用，同时仍向用户公开；
- 软件只依据来源中的明确说明自动分组，不凭空间位置猜测；
- 不明确的包含关系继续交给用户评审。
