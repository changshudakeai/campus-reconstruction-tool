# ADR-0036：道路连通性——V2 不检查、不提醒、不自动修正

## 状态

已接受（2026-07-29，产品负责人确认；修订 ADR-0017 中 B15 的职责描述）

## 背景

一段道路即使两端都没有连接到其他道路，也可能是真实存在的独立道路、小径、环路或场地内部通道。仅凭道路是否与其他道路相连，无法可靠判断资料是否有问题。

如果把这类道路统一标成疑点，会让用户处理大量无法据此判断对错的提醒。软件也没有足够依据擅自延长、吸附、连接或删除道路。

## 决定

- V2 不把道路是否连接到其他道路作为质量判断；
- B15 不检查或报告道路连通性，不在评审、采集报告、通知中心或导出确认中显示此类提醒；
- 不自动延长、吸附、连接、裁切或删除道路；
- 道路仍作为普通候选独立进入评审，由用户按现有三态规则决定去留；
- 道路自身形状损坏仍按 B14 和 ADR-0032 处理，这与道路是否连接无关；
- 本 ADR 修订 ADR-0017 中 B15“道路连通性规则”的职责描述：V2.0.0 不实现该行为。

## 后果

- 正常存在的独立道路不会产生误报；
- 用户不需要根据不足以判断真假的信息做决定；
- B15 在 V2.0.0 聚焦建筑重叠、明确建筑组成关系和不同类别的明显位置冲突；
- 将来若有真实使用证据表明需要道路连通性检查，必须重新进行产品决策。
