# ADR-0032：候选几何检查——隔离单个问题对象，不阻断整次采集

## 状态

已接受（2026-07-29，产品负责人确认；同日修订：问题对象直接排除，不提供人工修形；2026-08-01 由 ADR-0040 补充原始观测/评审候选分层、形状种类和候选资格契约）

## 背景

采集数据可能包含损坏或不完整的形状，例如建筑轮廓自相交、水域面积为零、道路缺少有效点。一次采集通常包含数百个对象，不能因为其中一个对象有问题就让整批结果作废。

方案的校区边界已经由 B5 `foundation-mode` 按 ADR-0029 检查点数不足、自相交和面积过小；B14 不重复承担方案边界校验。B14 面向采集回来的建筑、道路、水域、植被、体育和其他候选对象。

## 决定

- B14 对采集候选逐个检查，单个候选的问题不得阻断其他候选进入评审，也不得让整次采集失败；
- 无法安全自动修复的对象直接从本次候选列表中排除，不进入评审，也不得进入导出；
- 不提供单个候选的地图修形功能；数据源形状有问题时由校验阶段直接排除；
- 被排除对象的原始采集记录继续保存在数据粮仓中，不删除原始证据；
- 采集报告必须明确显示“因形状问题剔除 N 个对象”，禁止无提示地消失；
- 不改变实际外观且结果唯一的小问题由软件自动修复，包括轮廓未闭合、连续重复点和首尾多余重复点；不逐项弹窗，采集报告汇总显示“已自动修复 N 个对象”；
- 可能改变真实形状的问题禁止自动猜测，包括轮廓自相交、面积为零、有效点不足或坐标明显错误；这些对象按上述规则直接排除。

## 后果

- 一个坏对象不会拖垮数百个正常对象；
- 无歧义的小问题由软件消化，有歧义的问题直接排除，不增加人工修形工作流；
- 问题对象不会出现在评审列表，但排除数量在采集报告中透明可查，原始记录仍保留；
- B14 与 B5 分工清楚：B5 管方案边界，B14 管采集候选形状。
