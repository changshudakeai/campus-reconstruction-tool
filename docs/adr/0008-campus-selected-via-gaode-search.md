# ADR-0008：校区通过高德搜索选定，而非自由命名

## 状态

已接受（2026-07-25，产品负责人确认）

## 背景

最初的流程草案把"添加校区"设想为用户手动起名。产品负责人纠正：不可能去建一个不存在的学校，校区必须对应真实学校；用户在输入想复刻的学校名称时就应调用高德服务搜索，并对结果做筛选以避免混淆。

## 决定

添加校区的唯一途径是**搜索并选定真实学校**：

1. 用户输入学校名称关键词，应用调用高德地点搜索；
2. **结果筛选**：只保留学校类地点（高校、中小学等教育类目），过滤掉以学校命名的公交站、地铁站、校门、银行网点等干扰项；同名/近名结果去重；
3. 候选列表每项展示：学校名称 + 所在地址（含行政区），多校区大学（如"华东师范大学(普陀校区)"与"(闵行校区)"）作为独立候选并列展示；
4. 用户点选一项后校区即建立：校区名称、坐标锚点均取自高德数据，用户不手动输入校区名；
5. 此后该校区下所有方案画边界时，地图直接定位到该锚点。

## 后果

- 校区名称规范、无错别字，多校区歧义在源头解决。
- 校区层持久化字段：高德地点标识、名称、地址、坐标锚点。
- 添加校区依赖网络与高德服务可用；失败与空结果的处理策略需单独决策。
- "创建校区"一词在产品文案中改为"添加校区"（从真实学校中选定）。
