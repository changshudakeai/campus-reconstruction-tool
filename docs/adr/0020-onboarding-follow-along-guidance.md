# ADR-0020：新手教程采用跟练式引导——真实操作中当场指路

## 状态

已接受（2026-07-25，产品负责人确认）

## 背景

v1.x 的新手教程是"说明书式"：首次启动弹五页图文引导 + 内置三截图快速开始。用户看完就忘，真正上手仍靠摸索。

V2 的工作区本身是任务链（ADR-0012："一次只给用户一个当前任务"），软件自己会领路；产品原则为"任务驱动而非配置驱动"。据此重新决策教程形态。

曾考虑并否决：
- **说明书式**（首次启动弹图文引导页）——被"任务驱动"原则排斥，且无人认真阅读；
- **示例方案式**（内置做好一半的示例校园供参观）——需维护示例数据，且"看样板"不等于"会干活"。

## 决定

### 一、形态：跟练式引导（learn by doing）

不设单独的教程页。用户直接开始建第一个真实方案，软件在真实操作里当场指路：

- 第一次进方案列表页 → 气泡提示"点这里新建方案"；
- 第一次进地图 → 气泡提示"在地图上圈出校园范围"；
- 每完成一步，提示下一步——气泡是任务链的旁白，不是独立课程。

教程做完，用户手里已经有第一个真实作品。

### 二、气泡的四条规矩

| 规矩 | 内容 |
|------|------|
| ① 每个气泡可关 | 气泡上有"知道了"，点击即消失 |
| ② 一键全跳 | 第一个气泡附"跳过全部引导"选项，选择后所有气泡永不再出现 |
| ③ 只教一次 | 每个提示点只在第一次遇到时出现；建第二个方案时全程安静 |
| ④ 可以重看 | 设置中提供"重新开启新手引导"，跳过可逆 |

引导状态（已见过哪些提示点、是否全跳）为应用级持久化状态。

### 三、实施顺序约束（产品负责人特别要求）

**跟练引导的开发必须排在主界面基本成型、且产品负责人审核认可界面美观度之后**——教练等健身房装修完才上岗。气泡的具体位置与文案在该次界面审核时一并敲定；文案一律走外置资源文件（ADR-0005）。

## 后果

- 引导与任务链天然一体：工作区领路，气泡旁白，学的过程就是做的过程；
- 引导不碰业务数据、不阻挡操作，最坏情况是气泡未出现，不影响任何功能；
- F2 模块（onboarding-tutorial）在实施排期上依赖 S1 应用壳与各功能模块的界面定稿，属于后期工单；
- 气泡提示点清单不在本 ADR 固化，留给界面审核阶段决定（避免对着还不存在的界面空谈位置）。
