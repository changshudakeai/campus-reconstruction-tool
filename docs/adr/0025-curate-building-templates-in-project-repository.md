# Curate parametric building templates in the project repository

Rather than searching GitHub at runtime, maintainers commit versioned Parametric Building Templates with source and license provenance to this repository so users can apply them directly from the Building Template Catalog.

GitHub is the distribution, versioning, review, and community-contribution channel, not the only source of architectural knowledge. Maintainers may author original rules from Eligible Building Style References including open-source building projects, lawfully reusable official imagery, Official 3D Reference Captures, and Field Building Photographs. The catalog should first cover recurring Chinese university archetypes such as Republican-era historic buildings, Soviet-influenced teaching blocks, late-twentieth-century teaching buildings, red-brick dormitories, modern glass complexes, and contemporary Chinese-style buildings.

Catalog navigation and matching use architectural period and construction language as primary dimensions. University names remain optional case labels rather than styles. A user-confirmed Visual Evidence Crop may retrieve the closest catalog templates by photo match and generate Photo-Guided Appearance Proposals without changing measured massing.

Third-party source files are mirrored only when their license permits redistribution. Otherwise a template records a source link, evidence lineage, and applicable rights without copying the original material or finished building.
