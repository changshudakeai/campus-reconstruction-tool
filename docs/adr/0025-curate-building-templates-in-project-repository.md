# Curate parametric building templates in the project repository

Rather than searching GitHub at runtime, maintainers commit versioned Parametric Building Templates with source and license provenance to this repository so users can apply them directly from the Building Template Catalog.

GitHub is the distribution, versioning, review, and community-contribution channel, not the only source of architectural knowledge. Maintainers may author original rules from Eligible Building Style References including open-source building projects, lawfully reusable official imagery, Official 3D Reference Captures, and Field Building Photographs.

V1 contains fixed Arnis Style Presets derived directly from the complete version-pinned upstream Arnis exterior categories. Chinese university archetypes and photo-guided catalog retrieval are V2 work: they require evidence, curation, and matcher validation before entering the catalog. At that point catalog navigation and matching use architectural period and construction language as primary dimensions, while university names remain optional case labels rather than styles. A user-confirmed Visual Evidence Crop may retrieve the closest catalog templates by photo match and generate Photo-Guided Appearance Proposals without changing measured massing.

Third-party source files are mirrored only when their license permits redistribution. Otherwise a template records a source link, evidence lineage, and applicable rights without copying the original material or finished building.
