# Port complete Arnis exterior rules without its world generator

Detailed Building Mode will expand the vendored, version-pinned Rust adapter into an Arnis Exterior Rule Engine that preserves the complete upstream building-exterior behavior through the existing in-memory block sink. Interiors, terrain, roads, GUI, CLI, whole-world orchestration, and Minecraft world writers remain outside this boundary so screenshot-guided regeneration stays deterministic and building-scoped.
