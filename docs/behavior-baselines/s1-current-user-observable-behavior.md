# S1 当前用户可观察行为基线

> 工单 01，2026-07-30。后续 S1 结构迁移必须保持本基线；若确认产品行为需要改变，
> 应另立工单并更新相应 ADR 与本基线。

## 观察边界

本基线只观察用户能够直接看到或操作的四个通道：

- **页面**：当前显示的页面、弹窗和页面内可见内容；
- **状态**：就绪、处理中、完成、失败、待确认等可见状态和进度；
- **通知**：短暂提示、错误弹窗与通知中心记录；
- **导航**：操作完成后停留、前进或返回到哪个页面。

本基线不固定内部函数或数据结构，也不固定模块装配、线程、消息、存储或计算实现。

## 结果类型

| 结果 | 用户可观察含义 |
|---|---|
| **成功** | 页面显示完成结果或最新数据；需要前进的操作导航到既定下一页；成功反馈按既有规则显示。 |
| **失败** | 当前操作不被当作成功；保留用户仍需继续处理的上下文；通过错误弹窗或通知说明失败。 |
| **处理中** | 耗时操作开始后立即显示处理中状态或进度；窗口和无关功能保持可响应；完成前不显示成功结果。 |
| **需要确认** | 在删除、清空、批量剔除、封账或覆盖影响等既定场景显示确认弹窗；取消后停留原处且不提交操作。 |

四类结果是逐流程记录维度，并不表示每个流程都已实现这些状态；占位流程必须明确记录“当前没有可观察结果”，不得以目标行为代替现状。

## 流程基线

| 流程 | 页面与初始状态 | 成功 | 失败 | 处理中 | 需要确认 | 导航与通知 |
|---|---|---|---|---|---|---|
| **启动** | 首次启动显示基本设置；已有设置且上次校区可用时显示该校区的方案列表；没有可用校区时显示校区选择。 | 着陆结果确定后显示对应页面，不自动进入具体方案。 | 数据库无法打开时，界面仍显示默认的校区选择页，但状态文案按首次设置显示；首次运行状态读取失败时显示首次设置；上次校区读取失败时显示校区选择；这些分支均不显示错误。此现状与 ADR-0037 的目标不一致，后续须另立工单处理。 | 启动判定完成前只显示启动状态。 | 当前流程没有需要用户确认的分支。 | 只导航到基本设置、校区选择或方案列表之一；上述读取失败不会生成通知。 |
| **设置** | 首次设置显示语言、Minecraft 版本和知情告知；常规设置只显示教程重播、高德 API Key 与安全密钥、保存、同步连通性测试和返回入口。当前没有默认导出位置、清空全部密钥或测试中状态。 | 勾选知情告知并继续后完成首次设置；密钥保存或同步测试成功时通过通知中心提示。 | 未勾选知情告知时仍停留首次设置；密钥保存或同步测试失败时显示错误弹窗。 | 保存与同步测试当前同步执行，没有可观察的处理中状态。 | 当前设置页没有清空密钥入口，也没有对应确认状态。 | 首次设置成功后导航到校区选择；常规设置返回校区选择；保存与测试后停留设置页并按结果通知。 |
| **校区与方案** | 校区选择页显示已有校区、新建演示校区和设置入口；方案列表显示当前校区、方案卡片、创建入口和回收站入口。当前没有校区搜索输入或搜索结果页。 | 新建或选中校区后进入方案列表；创建、改名、复制或删除成功后刷新相应列表。回收站的恢复、永久删除和清空当前没有可观察效果。 | 标识无效、持久化或操作失败时停留当前页面，并通过错误弹窗说明。 | 这些操作当前同步执行，没有可观察的处理中状态。 | 创建和改名使用输入弹窗；删除方案使用确认弹窗，取消后不提交。回收站的永久删除和清空当前不会显示确认弹窗。 | 选中方案导航到五步工作区；返回、设置、回收站入口按当前屏号切换；回收站操作不导航也不通知；其余错误经通知路径显示。 |
| **五步流程** | 工作区显示边界、朝向、采集、评审、导出五步；当前仅边界与朝向有交互页，采集、评审、导出显示待实现占位页。 | 边界或朝向确认成功后更新当前状态及已完成步数，并解锁下一步。 | 校验失败时停留边界或朝向步骤、保留可继续修改的状态，并显示错误。 | 当前边界与朝向没有统一的可观察处理中状态；步骤③至⑤也不执行后台任务。 | 缺少高德密钥时进入边界会显示前往设置确认；覆盖既有朝向时按当前规则确认。 | 已解锁步骤可切换；锁定步骤忽略点击；步骤③至⑤即使解锁也只导航到占位页，不产生完成或失败通知。 |
| **采集** | 当前仅显示占位页：标题和“步骤待实现”提示，没有开始按钮、结果摘要或任务状态。 | 当前没有可观察的采集成功结果。 | 当前没有可观察的采集失败结果。 | 当前没有可观察的采集处理中状态。 | 当前没有可观察的采集确认状态。 | 步骤解锁后只能导航到采集占位页；不产生采集通知，也不解锁评审。 |
| **评审** | 当前仅显示占位页：标题和“步骤待实现”提示，没有候选卡片、批量操作或封账状态。 | 当前没有可观察的评审成功结果。 | 当前没有可观察的评审失败结果。 | 当前没有可观察的评审处理中状态。 | 当前没有可观察的评审确认状态。 | 步骤解锁后只能导航到评审占位页；不产生评审通知，也不进入真实导出流程。 |
| **导出** | 当前仅显示占位页：标题和“步骤待实现”提示，没有摘要、目标位置、确认按钮或进度。 | 当前没有可观察的导出成功结果或输出位置。 | 当前没有可观察的导出失败结果，也不存在失败后返回评审的行为。 | 当前没有可观察的导出处理中状态。 | 当前没有可观察的导出确认状态。 | 步骤解锁后只能导航到导出占位页；不执行导出、不生成文件，也不产生导出通知。 |

## 迁移验收

后续结构工单至少应证明：

1. 上述页面、状态、通知和导航结果没有无意变化；
2. 成功、失败、处理中和需要确认四类结果仍可从公开 UI 接缝观察；
3. 测试不读取正式数据库或私有状态来替代用户可见结果；
4. 若发现现有行为与已接受 ADR 不一致，另立工单，不在薄壳迁移中顺手改变。
