# S1 当前用户可观察行为基线

> 工单 01，2026-07-30。后续 S1 结构迁移必须保持本基线；若确认产品行为需要改变，
> 应另立工单并更新相应 ADR 与本基线。

## 观察边界

本基线只观察用户能够直接看到或操作的四个通道：

- **页面**：当前显示的页面、弹窗和页面内可见内容；
- **状态**：就绪、处理中、完成、失败、待确认等可见状态和进度；
- **通知**：短暂提示、错误弹窗与通知中心记录；
- **导航**：操作完成后停留、前进或返回到哪个页面。

本基线不固定内部函数或数据结构，也不固定模块装配、线程、消息、存储或计算实现。

## 结果类型

| 结果 | 用户可观察含义 |
|---|---|
| **成功** | 页面显示完成结果或最新数据；需要前进的操作导航到既定下一页；成功反馈按既有规则显示。 |
| **失败** | 当前操作不被当作成功；保留用户仍需继续处理的上下文；通过错误弹窗或通知说明失败。 |
| **处理中** | 耗时操作开始后立即显示处理中状态或进度；窗口和无关功能保持可响应；完成前不显示成功结果。 |
| **需要确认** | 在删除、清空、批量剔除、封账或覆盖影响等既定场景显示确认弹窗；取消后停留原处且不提交操作。 |

## 流程基线

| 流程 | 页面与初始状态 | 成功 | 失败 | 处理中 | 需要确认 | 导航与通知 |
|---|---|---|---|---|---|---|
| **启动** | 首次启动显示基本设置；已有设置且上次校区可用时显示该校区的方案列表；没有可用校区时显示校区选择。 | 着陆结果确定后显示对应页面，不自动进入具体方案。 | 数据库无法打开或首次运行状态读取失败时，当前实现静默显示首次设置；上次校区读取失败时，当前实现静默显示校区选择；均不显示错误。此现状与 ADR-0037 的目标不一致，后续须另立工单处理。 | 启动判定完成前只显示启动状态。 | 当前流程没有需要用户确认的分支。 | 只导航到基本设置、校区选择或方案列表之一；上述读取失败不会生成通知。 |
| **设置** | 首次设置显示语言、Minecraft 版本和知情告知；常规设置显示当前已保存值及高德密钥、默认导出位置等既有项目。 | 首次设置完成后进入校区选择；常规保存后立即生效并显示成功提示。 | 必填项或格式不合规时不保存并显示原因；连通性或保存失败按既有严重程度显示结果或错误弹窗。 | 联网测试期间显示正在测试。 | 清除全部高德密钥前需要确认，取消则不变。 | 保存常规设置后停留设置页；首次完成按既有流程前进；通知按保存、测试或清除结果显示。 |
| **校区与方案** | 校区选择页显示搜索结果或最近使用校区；方案列表显示当前校区名、方案卡片和回收站入口。 | 选中校区进入其方案列表；创建、改名、复制、恢复等成功后列表显示最新结果。 | 搜索或保存失败时保留输入与当前页面；不创建半成品结果，并显示错误。 | 搜索等耗时操作显示处理中。 | 删除方案、永久删除和清空回收站在既定场景需要确认。 | 进入方案后导航到五步流程；恢复后仍停留回收站；各操作按既有规则显示短暂提示或错误通知。 |
| **五步流程** | 方案内始终显示边界、朝向、采集、评审、导出五步及当前步骤；边界与朝向显示当前是否已确定。 | 完成当前必经步骤后更新步骤状态，并允许进入已解锁步骤。 | 校验失败时停留当前步骤、保留可继续修改的页面状态并显示原因。 | 后台工作由对应步骤显示处理中。 | 重置或会影响既有结果的操作按既有规则需要确认。 | 点击可用步骤导航到该步骤；锁定步骤不被当作成功进入；错误进入通知路径。 |
| **采集** | 采集页显示就绪状态和开始操作；已有结果时显示最近一次摘要。 | 完成后显示完成状态与结果摘要，并使后续评审可用。 | 失败后显示失败状态，不显示完成结果；错误通过既有弹窗或通知说明。 | 开始后立即显示处理中，完成前禁止重复开始但窗口保持可响应；离开是否安全由当前任务结果决定。 | 当前流程没有额外的用户确认。 | 完成后停留采集页供用户查看结果；通知说明成功或失败。 |
| **评审** | 评审页显示分类、候选卡片、三态结果和当前选择；封账后显示封账状态。 | 单项或批量修改后卡片、计数和选择状态立即反映结果。 | 操作失败时不显示为已应用，页面保留可继续评审的状态并显示错误。 | 执行批量操作时页面维持当前评审上下文。 | 批量剔除达到既定数量时需要确认；取消后不改变评审结果。 | 评审操作通常停留本页；进入导出时按封账规则导航，通知显示异常结果。 |
| **导出** | 导出页显示摘要、待定项提示、封账说明、目标位置与可执行状态。 | 完成后显示导出结果和成功位置，进度达到完成状态。 | 失败后停止导出、显示错误，并返回评审步骤以继续处理；不得显示虚假成功文件。 | 执行中在导出页显示非阻塞进度。 | 开始导出前需要确认封账及既有风险；取消确认则不开始。 | 导出期间停留导出页；成功仍停留并显示结果；失败显示错误通知后导航回评审步骤。 |
## 迁移验收

后续结构工单至少应证明：

1. 上述页面、状态、通知和导航结果没有无意变化；
2. 成功、失败、处理中和需要确认四类结果仍可从公开 UI 接缝观察；
3. 测试不读取正式数据库或私有状态来替代用户可见结果；
4. 若发现现有行为与已接受 ADR 不一致，另立工单，不在薄壳迁移中顺手改变。
