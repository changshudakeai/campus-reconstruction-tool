# S1 当前用户可观察行为基线

> 工单 01，2026-07-30。后续 S1 结构迁移必须保持本基线；若确认产品行为需要改变，
> 应另立工单并更新相应 ADR 与本基线。

> [!IMPORTANT]
> 本文记录的是**当前已实现行为**，不是最新目标产品。ADR-0041 已确认目标变更：方案边界是唯一导出前置，自定义朝向可选且未设置时默认地图正北，候选采集/评审不阻塞导出。对应代码和验收完成前，本文中的旧五步锁仍用于辨认实现差距，不得反过来否定产品基线。

## 观察边界

本基线只观察用户能够直接看到或操作的四个通道：

- **页面**：当前显示的页面、弹窗和页面内可见内容；
- **状态**：就绪、处理中、完成、失败、待确认等可见状态和进度；
- **通知**：短暂提示、错误弹窗与通知中心记录；
- **导航**：操作完成后停留、前进或返回到哪个页面。

本基线不固定内部函数或数据结构，也不固定模块装配、线程、消息、存储或计算实现。

## 结果类型

| 结果 | 用户可观察含义 |
|---|---|
| **成功** | 页面显示完成结果或最新数据；需要前进的操作导航到既定下一页；成功反馈按既有规则显示。 |
| **失败** | 当前操作不被当作成功；保留用户仍需继续处理的上下文；通过错误弹窗或通知说明失败。 |
| **处理中** | 耗时操作开始后立即显示处理中状态或进度；窗口和无关功能保持可响应；完成前不显示成功结果。 |
| **需要确认** | 在删除、清空、批量剔除、封账或覆盖影响等既定场景显示确认弹窗；取消后停留原处且不提交操作。 |

四类结果是逐流程记录维度，并不表示每个流程都已实现这些状态；占位流程必须明确记录“当前没有可观察结果”，不得以目标行为代替现状。

## 流程基线

| 流程 | 页面与初始状态 | 成功 | 失败 | 处理中 | 需要确认 | 导航与通知 |
|---|---|---|---|---|---|---|
| **启动** | 首次启动显示基本设置；已有设置且上次校区可用时显示该校区的方案列表；没有可用校区时显示校区选择。 | 着陆结果确定后显示对应页面，不自动进入具体方案。 | 正式数据无法读取时呈现明确失败状态与错误通知，不切换到内存数据或假首开页；失败后重新请求同一入口即可重试。 | 启动判定完成前只显示启动状态。 | 当前流程没有需要用户确认的分支。 | 只导航到基本设置、校区选择或方案列表之一；读取失败经通知中心生成错误通知。 |
| **设置** | 首次设置显示语言、Minecraft 版本和知情告知；常规设置显示常规设置（语言、Minecraft 版本、默认导出位置）与高德地图密钥（API Key、安全密钥）、保存密钥、测试连通性、清除全部密钥、教程重播和返回入口。 | 勾选知情告知并继续后完成首次设置；常规设置保存、密钥保存或同步测试成功时通过通知中心提示；确认清除密钥后短暂提示“高德密钥已清除”。 | 未勾选知情告知时仍停留首次设置；设置读取、密钥保存或同步测试失败时显示错误弹窗并停留设置页可重试。 | 保存与同步测试当前同步执行，没有可观察的处理中状态。 | 清除全部高德密钥显示确认弹窗，取消不提交；确认后一次清除全部密钥。 | 首次设置成功后导航到校区选择；常规设置返回校区选择；保存、测试与清除后停留设置页并按结果通知。 |
| **校区与方案** | 校区选择页显示搜索框、最近使用的校区（名称+地址）和设置入口；方案列表显示当前校区、方案卡片、创建入口和回收站入口；没有最近记录时直接显示搜索框。 | 搜索只在点击“搜索”或按回车时开始（T30：高德在线搜索，结果仅学校类，点选后经详情确认建/选校区）；选择校区（含重复校区）进入其方案列表，重复校区附“该校区已添加，已为你切换”通知；创建、改名、复制或删除成功后刷新相应列表；回收站恢复、永久删除和清空成功后在回收站停留并短暂提示。 | 标识无效、持久化或操作失败时停留当前页面，通过错误弹窗说明；校区搜索失败弹“暂时无法搜索”并提供重试/取消，取消不建校区；单个方案操作失败不影响方案页其余功能。 | 校区搜索有可观察的处理中状态；方案 CRUD 操作当前同步执行，没有可观察的处理中状态。 | 创建和改名使用输入弹窗；删除方案、立即永久删除与清空回收站使用确认弹窗，取消后不提交；移除最近记录不弹确认。 | 选中方案导航到五步工作区；返回、设置、回收站入口按当前屏号切换；回收站操作后停留回收站并产生通知；其余错误经通知路径显示。 |
| **五步流程** | 工作区显示边界、朝向、采集、评审、导出五步，五个步骤顶部始终同时显示校区名与方案名（ADR-0027）；边界、朝向与采集有交互页，评审显示三态评审工作台（无候选时为空态），导出显示边界直出确认入口；朝向步骤提供两点参考线与方位角输入两种模式，两点模式在地图画完两点后立即显示参考线、方向箭头与计算角度。 | 边界、朝向或采集完成后更新当前状态及已完成步数并解锁下一步；评审封账成功后显示导出摘要并落库终态；步骤点击由工作区功能入口返回允许进入决定并呈现目标步骤；地图“清除重来”只清除未确认草稿，不清除已保存朝向。 | 校验失败时停留边界或朝向步骤、保留可继续修改的状态并显示错误；朝向保存失败时正式状态保持不变并显示明确错误；封账写回失败时评审状态保持可修改并显示明确错误；步骤条件不足时由功能入口拒绝进入并停留。 | 需要加载地图、采集或导出时界面立即显示处理中状态且不冻结；导出后台呈现 F9 真实阶段进度。 | 缺少高德密钥时进入边界会显示前往设置确认；覆盖既有朝向时先显示影响说明与确认窗，确认后生效、取消不落库；批量剔除 >=5 项时显示二次确认窗，确认后执行、取消后状态不变；离开边界页且存在未确认的边界绘制时显示确认窗，取消停留、确认后离开。 | 已解锁步骤可切换；锁定步骤忽略点击；评审导航到三态评审工作台且无候选不阻塞导出，导出在边界确认后可直接开始并呈现成功或失败；地图加载中离开边界页必须停留；高德地图故障只暂停地图相关操作，设置、方案列表与已有正式数据仍可访问，并留底公告。 |
| **采集** | 采集页显示高德来源、六类对象及初始“待定”状态、采集按钮和常驻“查看采集报告”入口。 | 采集完成显示对象总数、各类计数和新增/更新/未变摘要，方案卡片下一步变为评审；报告可查看类别汇总与本次体检结果。 | 数据源或采集失败时停留采集页，保留可重新采集入口；已成功保存的数据仍可查看。 | 点击采集后立即显示“正在从地图平台拉数据……”，网络结果回传前窗口保持可响应。 | 覆盖率无疑点时静默通过；有疑点时经 B7 合并为一扇“知道了”错误模态窗，同一批疑点关闭后不再主动弹出。 | 步骤解锁后进入采集页；采集完成后不自动离开页面，覆盖率弹窗由通知中心留底，报告入口始终可用。 |
| **评审** | 进入评审台后按六类标签页显示可评审候选（标题、三态、复选），无候选时显示明确空态；提供逐项三态判定、批量操作、暂停/恢复与封账入口。 | 封账成功后显示导出摘要（保留/待定/剔除计数与按类别保留明细），终态落库；重新进入恢复上一轮已封账终态。 | 封账写回失败或会话读写失败时经 B7 错误弹窗呈现结构化失败，评审状态保持可修改，不显示成功产物。 | 当前评审操作全部同步完成，没有可观察的处理中状态。 | 批量剔除 >=5 项时显示二次确认弹窗，确认后执行、取消后状态不变。 | 步骤解锁后可进入评审页；无候选不阻塞导出也不伪造评审完成；评审页只呈现 F5 返回的页面状态与通知，不编排业务。 |
| **导出** | 边界确认后显示导出确认入口与边界直出说明，不要求朝向、采集或评审完成。 | 后台完成后显示导出完成和实际产物位置，生成 `.schem` 与 manifest。 | 生成、版本核对或落盘失败时显示失败状态并保留已确认边界，可重试。 | 点击开始后立即显示处理中和真实阶段进度，窗口保持可响应。 | 当前导出无需额外封账确认；边界确认是唯一资格条件。 | 完成或失败均留在工作区并由导出入口呈现状态；失败不显示成功产物。 |

## 迁移验收

后续结构工单至少应证明：

1. 上述页面、状态、通知和导航结果没有无意变化；
2. 成功、失败、处理中和需要确认四类结果仍可从公开 UI 接缝观察；
3. 测试不读取正式数据库或私有状态来替代用户可见结果；
4. 若发现现有行为与已接受 ADR 不一致，另立工单，不在薄壳迁移中顺手改变。
