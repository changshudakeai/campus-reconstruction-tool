# V1.1 live-service and Axiom evidence

Use one copy of `v1.1-live-axiom-operator-record.template.json` beside the
referenced manifests, schematics, deterministic repeat exports, and screenshots.
Replace every placeholder with observations from the exact installed candidate.
Replace every category entry with the complete shape shown in
`coverageReportRequiredFields`; that top-level example is instructional and may
be removed from the completed record. Acquisition Licence Manifests must contain
a non-empty `sources` array, and each risk exercise must link its result files.
Do not paste Gaode keys, security codes, service credentials, or authorization
headers into diagnostics.

The five full-flow campuses each require one current-revision Foundation export;
Putuo also requires one Detailed export. Generate every output a second time from
the same reviewed project revision and record it as `determinismRepeat`. Import
all six primary files into the recorded clean Minecraft Java Edition 26.1.2 and
Axiom instance. The two screenshots for each import must together show
orientation/placement and principal features.

NYU Shanghai Qiantan is the required `boundary-unavailable` case. Its record must
show retry, back, refresh, persisted diagnostic lineage, no fabricated geometry,
and no five-category review or export. If the accepted matrix replacement rule is
invoked, update the validator and template in a new candidate before collecting
evidence; do not silently substitute a campus in an existing candidate record.

Run the collector from a standard-user PowerShell session:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/collect-v1-1-live-axiom-evidence.ps1 `
  -CandidateDirectory <candidate-directory> `
  -OperatorRecord <operator-record.json>
```

The collector fails closed unless candidate and installed identities match. It
copies the complete source record directory into a new evidence directory, runs
the installed `campus-native.exe` validator, hashes the input/report and all
installed binaries, and retains every mandatory failure as a Release Blocker.
An existing evidence directory is never overwritten.
