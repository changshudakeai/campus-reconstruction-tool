# V1.1 operator-experience evidence

This evidence must come from the exact installed candidate on Windows 11 x64. The operator must not be a developer and must have no repository, toolchain, fixture, or developer utility. Give the operator only this goal:

> Independently create and export a Minecraft campus reconstruction project, using the application's own guidance when needed.

Do not give a step-by-step script. Record every hesitation, error, request for assistance, abandonment, and blocking developer explanation as it happens. Keep the operator's wording. The release owner may explain how to record evidence, but must not explain how to complete the product workflow.

After the independent run, exercise the explicit evidence matrix in `v1.1-operator-experience-record.template.json`: first-run/skip behavior; reopening guidance through `F1`, `?`, and Settings; shortcut priority and disabled reasons; one-layer `Esc`; Chinese and English all-screen/error sweeps; and 100%, 125%, and 150% Windows scaling with visible focus, escapable modals, and keyboard access to core non-map actions.

Copy the template and keep all referenced screenshots, logs, project files, portable files, and other evidence below the record's directory. List every referenced screenshot separately as a `screenshot` scanned artifact, hash it, inspect its visible pixels for credentials, and set `visualInspectionPassed` only after that human inspection. Secret fields must remain masked. Never paste keys, security codes, tokens, authorization headers, or credentials into the record or evidence. Classify assistance by whether it affected independent product completion; evidence-capture help alone is permitted, but unclassified or workflow assistance fails closed.

Keep artifacts unpacked. ZIP, 7z, RAR, tar, and other archive containers are rejected because their contents cannot be proven secret-safe by the installed validator.

Run from a standard-user PowerShell session:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/collect-v1-1-operator-experience-evidence.ps1 `
  -CandidateDirectory <candidate-directory> `
  -OperatorRecord <operator-record.json>
```

The collector copies the source evidence without replacing an existing bundle, verifies candidate and installed binary identity, invokes the installed release binary, hashes the record/report/binaries, and scans textual evidence for configured secret values. Missing guidance, exposed secrets, unreadable critical UI, inability to complete independently, or any mandatory failed assertion is a Release Blocker. Do not reinterpret a failed case as a waiver.
