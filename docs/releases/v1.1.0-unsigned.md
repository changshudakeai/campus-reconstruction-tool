# Campus Reconstruction Tool V1.1.0 candidate

This controlled-release candidate supports Windows 11 x64 and requires network
access for Gaode Campus Target search and new/refresh Foundation acquisition.
Persisted projects and pinned evidence remain locally editable.

## Unsigned installer

The candidate is currently unsigned. Windows SmartScreen may show an
"unrecognized app" warning. Before running it:

1. Compare the installer SHA-256 with the exact value in the candidate's
   generated `distribution.json` or `DISTRIBUTION.md`.
2. Confirm the source commit in `release-candidate.json` matches the published
   source statement.
3. If the hashes match, choose **More info** and **Run anyway**.

Do not bypass SmartScreen when the SHA-256 or source commit differs.

## Source statement

The installer is produced from the clean Git commit recorded in
`release-candidate.json`. Packaging consumes the three already-tested release
executables recorded in that manifest, verifies their SHA-256 before and after
NSIS inclusion, and does not rebuild them.

## Contents and support boundary

The installer contains only the three application executables, third-party
notices, this guidance, the candidate manifest, and the uninstaller. It does not
contain credentials, caches, fixtures, test projects, source code, or toolchains.

Installer size is recorded for information only; V1.1.0 has no 50 MB gate.
