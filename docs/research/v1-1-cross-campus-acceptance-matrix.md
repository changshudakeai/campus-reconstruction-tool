# V1.1 跨校区验收矩阵研究

研究日期：2026-07-17

## 结论

V1.1 的五所非普陀校区建议采用“故障行为均衡矩阵”：

1. 上海交通大学闵行校区（上海）
2. 武汉大学（武汉）
3. 厦门大学思明校区（厦门）
4. 西安交通大学兴庆校区（西安）
5. 上海纽约大学前滩校园（上海）

这五所学校覆盖四座城市。前四所用于完整流程和 `.schem` 产物验收；上海纽约大学前滩校园用于验证自动边界不可用、垂直校园和“没有围墙校园”场景下的诚实阻断、诊断和恢复行为。华东师范大学普陀校区仍是独立的深度案例，不计入这五所。

如果发布负责人决定五所学校都必须完成导出，则用西湖大学云谷校区（杭州）替换上海纽约大学前滩校园。但这会削弱“任意高德可搜索高校”承诺中最重要的负向行为验证，因此不推荐作为默认矩阵。

## 证据边界

- 大学官网用于确认正式校区名称、位置与校园形态。
- OpenStreetMap（OSM）当前元素用于候选预选和边界结构分类，不代表受控服务最终一定返回相同结果。
- 未使用公共 Overpass 的临时五层计数作为完整性结论。公共端点在研究期间发生超时，而 V1.1 正式架构要求受控 OSM/Overture 服务。
- 每个正式验收 Dataset Bundle 都必须保存版本化 Coverage Report，分别报告建筑、道路/通行、水域、植被和体育设施的 `complete`、`complete-empty`、`partial` 或 `failed` 状态，并记录查询范围、限制、分类规则版本和已知缺口。
- 票据 15 已确认当前桌面应用的高德 PlaceSearch 存在失败阻断。因此下列校名的高德 POI ID 与可搜索性必须在该阻断修复后通过同一正式验收环境复核；本研究不把高德控制台登录或官网地址误当成应用内搜索成功。

## 每个案例的验收判定

### 四个完整流程案例

上海交大闵行、武汉大学、厦大思明和西交大兴庆都必须：

1. 在修复后的正式高德环境中以明确校区候选被搜索、预览和确认，并保存稳定的 Campus Target 标识及原始候选快照。
2. 通过受控服务取得至少一个可解释的边界候选，完成选择或顶点微调并保存确认边界。
3. 生成版本化 Dataset Bundle 与五类 Coverage Report；类别可以是 `complete-empty` 或带已知缺口的 `partial`，但不能把空数组当成成功完整。
4. 保存五层审核决定、Known Feature Gaps、完成状态和来源版本；重启后跳过已完成步骤并进入下一未完成任务。
5. 运行重叠、包含、分类和几何修复规则；所有合并/拆分和修复都必须可审计、可撤销，并保留源候选。
6. 用 Minecraft Java Edition 26.1.2 兼容配置完成预览、生成和 Sponge `.schem` 导出，并通过 Axiom 验收。

### 前滩负向案例

前滩案例在下列条件下判定通过：

- 高德可确认具体的上海纽约大学前滩 Campus Target；
- 受控服务的查询、限制和候选诊断完整保存；
- 没有可信边界时明确停止在边界阶段；
- 用户能重试、返回校区选择或在未来数据更新后刷新；
- 未自动构造边界、未静默使用楼栋外轮廓替代校园边界、未进入五层审核或导出。

若受控服务届时确实返回可信的前滩校园边界，则保留该校作为“城市垂直/边界极小”案例，并从备用候选中再选择一个已验证的 `boundary-unavailable` 高校补足负向覆盖。

## 高德实机复核与替补规则

修复票据 15 的 PlaceSearch 阻断后，按表中正式中文校名逐一搜索，并记录：

- 高德返回的 POI ID、显示名、地址、行政区、坐标和原始候选快照；
- 是否出现同校多校区歧义，以及用户能否在地图上明确确认；
- 从搜索到 Campus Target 持久化的完整证据；
- 搜索调用错误码和配额，但证据中不得包含 key 或 security code。

某个候选仅在以下情况替换：

1. 正式高德环境不能稳定找到具体校区，或只能找到无法消歧的学校总名；
2. 候选与另一个案例覆盖的主要风险完全重复，且不能提供新的几何或服务行为；
3. 官方校区已迁移、合并或名称发生实质变化。

替补顺序：

1. 西湖大学云谷校区（杭州）——当前 OSM `way/587362728`，闭合 polygon；官网确认同心圆布局、环形水系和运动/生活分区。适合新校园、水域与规则化布局案例。
2. 中山大学深圳校区（深圳）——用于大型新校园替补，但与上海交大闵行的大尺度角色较重叠。
3. 香港中文大学（深圳）（深圳）——当前 OSM 为 multipolygon，可替代复杂边界案例，但与西交大兴庆的 multipolygon 角色部分重叠。

替换必须保持至少三座城市，并在矩阵记录中说明被替换原因。不能为了让结果“全绿”而删除唯一的已知缺口或边界不可用案例。

## 研究限制

- OSM 是持续更新的数据集；元素 ID 和几何必须在每次正式验收的 Dataset Bundle 中固定版本，不能只引用本文件的在线状态。
- 包络尺寸按经纬度边界近似换算，只用于分辨请求压力等级，不是法定或测绘意义上的校区面积。
- Overture 与五层分类结果尚未通过未来受控服务的生产式部署生成，因此本文只定义预期角色，不声称当前五类资源完整。
- 当前高德应用内搜索阻断尚未修复，推荐矩阵在关闭发布验收前仍需完成一次真实 PlaceSearch 复核。
