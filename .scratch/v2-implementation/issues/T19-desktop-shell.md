# T19 — S1 主程序应用壳（薄壳 UI + 开发版快捷方式）

> **后续收紧（2026-08-01）**：本文记录 Phase1 当时的实现范围；其中运行期白名单和“壳接线”表述不再授权业务编排。当前边界以 ADR-0037 为准：S1 对一个用户操作只调用一个完整功能入口，组合根只做构造期注入。

**What to build:** 零业务逻辑的 Slint 声明 + ViewModel 绑定；老用户着陆方案列表页；固定桌面快捷方式"校园复刻工具 - 开发版"每次构建后自动更新，保留上一可用版本兜底。

- **窗口契约**：壳只向完整功能入口请求页面状态和可执行操作；允许的共享显示类型或构造依赖不授权 S1 在运行期调用 B2-B18 完成业务。
- **业务规则**：薄壳原则（ADR-0037）：Slint 与 `apps/desktop/src` 都不能承担业务协调；一个 UI 回调只能跨越一个完整功能入口。
- **开发版快捷方式**：build.rs 或 xtask 子命令在构建后自动创建/更新快捷方式；旧版本备份到 backup/ 目录。

**Blocked by:** T01/T02/T03（三层锁 + 共享类型 + 文本外置先行完成）、T04-T18（功能模块全部就绪）
