# T06 — F5 候选审核工作台（三态评审 + 左中右布局）

**What to build:** 左卡片列表 + 中间大地图 + 右信息面板的三栏布局；所有候选初始为"待定"，逐个或批量裁决为保留/剔除；点错状态直接改点另一个状态（包括批量改回待定）；评审操作纯内存无卡顿，导出时才批量落盘。

- **窗口契约**：缝 4（评审 ↔ 存储）。进入评审台时一次性读入候选集到内存；评审期间不发生任何写库；导出确认后才批量写入 B2。
- **业务规则**：勾选 ≥2 个自动浮现"[全选][取消全选]"按钮；批量剔除 ≥5 项需二次确认，批量改保留/待定不需确认；地图上的对象高亮对应卡片（反之亦然）；随时暂停、保存项目、退出再回来继续。
- **三态**：待定（初始态，不导出不阻塞导出）、保留（唯一被导出）、剔除（永久排除无回收站）。

**Blocked by:** T01, T02, T03（共享类型 + 文本外置）, T11（B2 评审数据表结构与批量写回 API）

**Status:** completed
