# T07 — F9 导出控制台（封账确认弹窗 + 非阻塞进度条）

**What to build:** 点"导出地基"后弹出确认弹窗：类别汇总（本次保留建筑 X 栋、道路 Y 段）、封账后果说明（确认后评审结束不可改）、待定项报数（尚有 N 项不会被导出）；用户确认后评审入口禁用，右上角显示非阻塞进度条，完成自动跳转。

- **窗口契约**：缝 5（封账闸门 ↔ F9）。F5 向 F9 递交导出请求（保留项集合 + 类别汇总 + 待定计数）；F9 弹出确认弹窗并接管后续流程。
- **业务规则**：确认即封账（评审决定不可逆）；待定不阻塞导出；导出期间评审入口禁用但软件不冻结；出错时封账不生效保持可改状态。
- **弹窗铁律**：影响数据质量或卡住流程的错误必须模态弹窗，禁用横幅（ADR-0021）。

**Blocked by:** T06（F5 封账闸门递交导出请求）, T03（文本外置）, T11（B2 批量写回 API）, T15（B7 弹窗铁律 API）

**Status:** completed

> **ADR-0040 contract hardening（2026-08-01）**：F9 只接受 F5 封账后“保留”的稳定候选标识，并从同一份规范化候选投影取得生成输入；禁止查询原始观测或重新解释几何资格。既有确认弹窗与进度状态机保持不变。
