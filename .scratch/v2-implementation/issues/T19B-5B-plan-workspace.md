# T19B-5B — 方案工作区（单击打开 + 五格步骤条 + 圈边界 + 定朝向）

**What to build**: 方案工作区屏正式落地——单击方案卡片打开方案，顶部五格步骤条常驻，
主区域整屏显示当前步骤内容；实施前两个步骤页（① 圈边界、② 定朝向），完成后方案卡片进度推进到"下一步：采集"。
含 F2 提示点枚举改造与 stepper_intro 教程泡钩子。

- **窗口契约**: 缝 7（地图服务，Shell ↔ F 模块 ↔ B5/B3 中转）；Shell 展示边界绘制 ViewModel，几何计算全部在 B5
- **业务规则**: 朝向是必选步骤（决策记忆）；边界属于方案而非校区（ADR-0007）；修改朝向触发重算提示
  （`collection.orientation_recalc_notice` 已核实在库）
- **UI 决策法源**: ADR-0027（含第 2/3/6 轮子决策）+ ADR-0028（三泡清单）；与本单描述冲突时以 ADR 为准

**Blocked by**: T19B-5A（还债与基建：需要它的色卡机制、通用确认窗/输入窗）

**Status**: completed（2026-07-27 Phase 1 三步提交；Phase 2/3 债务转入 s1 批次 05/06）

## 🎯 验收标准

### 一、单击打开方案【ADR-0027 第 6 轮子决策】

- [ ] **单击方案卡片即打开方案**，进入方案工作区（取代 T19B-4 的"点击卡片无操作"暂定描述）
- [ ] **无概览中间层**（ADR-0027 第 6 轮明令否决"概览屏"）：打开后主区域直接整屏显示当前步骤内容，
  新方案首次打开即圈边界页
- [ ] ···菜单（T19B-5A 产物）仍在卡片右侧独立区域，与单击打开互不冲突

### 二、五格步骤条【ADR-0027 第 2/3/6 轮子决策】

- [ ] 窗口顶部横向步骤条，**五步全列**：① 圈边界 → ② 定朝向 → ③ 采集 → ④ 评审 → ⑤ 导出
  （复用已在库文本键 `collection.boundary_step` / `collection.orientation_step`，新步骤名按前缀规范补键）
- [ ] 状态呈现：当前格高亮、已完成格打勾、**未解锁格置灰不可点**（ADR-0027 第 6 轮）
- [ ] 跳转规则（ADR-0027 第 3 轮）：**回跳自由、改动弹窗确认、前跳上锁**——
  - 已完成步骤可自由点击回跳查看
  - 回跳页内真正修改边界或朝向时，弹确认窗（用 5A 通用确认窗）列明下游哪些已生成成果将被重算
    （复用 `collection.orientation_recalc_notice` 文案体系），确认后才生效，取消则不落库
  - 未解锁格必须按序完成前置步骤才解锁
- [ ] 第①格圈边界**永远处于解锁态**（ADR-0027 第 6 轮：无任何前置任务；新方案初始进度即"尚未确定范围"）
- [ ] 颜色一律走 5A 色卡角色名，零颜色号（5A 起门禁级红线）
