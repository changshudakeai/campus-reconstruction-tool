**What to build:** 按 ADR-0045 建立一个地图会话，在小接口后完整拥有边界、朝向、
评审的创建/切换/隐藏/弹窗恢复/延迟销毁和结构化命令；调用方不再判断页面种类、

**Blocked by:** T41.

## 验收与验证

- [x] 同一方案切换边界/朝向/评审时保持已确认的步骤现场；边界/朝向共享校园视野，
  评审记住候选与缩放；切换方案不串现场。
- [x] 未确认边界切评审/导出时只允许继续编辑或明确放弃；弹窗关闭恢复原步骤与现场。
- [x] 工作区与评审调用方不再使用 `is_*_page` / `is_visible` 判断，也不发送原始 JS；
  WebView2 代际、延迟销毁和失败抑制只在地图会话内部。
- [x] 地图失败不扩建复杂后备流程；正式已保存数据不失效，地图相关新操作明确暂停。
- [x] 地图会话状态机/结构化命令单测 + 相关 `s1_*` 边界/朝向/评审/导航/弹窗测试 +
  desktop-shell Clippy + fmt + tidy；真实 WebView 用既有剧本抽查。
- [x] 不改 Cargo/依赖/crate 拓扑，不触发 timings；最终完整门禁仍由 V2.1 版本收口统一兜底。
