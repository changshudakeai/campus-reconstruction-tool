# T38 评审工作台抽屉化改造（ADR-0016 更新 + 地图定位/标注）

Status: completed（2026-08-17 发布收口）
Blocked by: 无（可与 T37 并行；均基于本地稳定版 main）

## 决策（2026-08-09 产品负责人确认）

- ADR-0016 的三栏布局（左卡片 + 中地图 + 右信息面板）改为**抽屉样式**（与工作区其他步骤一致：地图为主区 + 左侧抽屉），ADR-0016 其余内容不变。
- 地图标注规则：**待定=虚线、保留=实线、剔除=地图隐藏**；剔除候选在卡片中仍保留，可改回保留/待定。
- 新增：候选卡片提供“定位到地图”按钮，点击后地图跳转到该候选并高亮；地图↔卡片联动高亮沿用 ADR-0016。

## 依据

- `docs/adr/0016-review-process-design.md`：三栏布局、地图↔卡片联动高亮、三态判定、批量操作（≥5 二次确认）、暂停/恢复、封账、内存操作无卡顿（本工单改为抽屉样式并保留其余）。
- 产品负责人 2026-08-09 决策（上述）。

## 范围

1. **ADR 更新**：修改 ADR-0016“界面布局”一节：三栏布局改为抽屉样式；记录标注规则（待定虚线/保留实线/剔除隐藏）与“定位到地图”交互；其余章节不变。
2. **评审步抽屉化**：评审步与工作区其他步骤一致——地图为主区 + 左侧抽屉；抽屉含：类别标签、候选卡片列表（可滚动，≥1000 候选封账可达，回归 T33）、选中候选详情（名称/标签/属性/来源，未命名显示“未命名建筑 #id”）、三态判定、批量操作、暂停/恢复、封账。
3. **地图定位与标注**：卡片“定位到地图”按钮 → 地图中心跳转并高亮；地图上按候选状态标注（待定虚线、保留实线、剔除隐藏）；点击地图对象高亮对应卡片（反之亦然）。
4. 明确不做：采集/导出/边界逻辑改动；产品基线其他变更。

## 验收标准（逐条证据）

1. ADR-0016 更新入库（三栏→抽屉 + 标注规则 + 定位交互），评审页与文档一致。
2. 评审抽屉：类别、列表滚动、详情、三态/批量/暂停/封账全部可用；≥1000 候选下封账按钮可达（回归 T33 场景）。
3. 定位按钮：点击后地图跳转并高亮候选（契约测试/截图）。
4. 标注规则：待定虚线、保留实线、剔除隐藏；剔除可从卡片改回（测试断言）。
5. 联动高亮：地图对象↔卡片双向高亮（ADR-0016）。
6. 回归 `cargo test -p desktop-shell --test s1_16 --test s1_17 --test s1_18` 全绿；全部门禁全绿（Windows，`SLINT_BACKEND=software`、`CARGO_BUILD_JOBS=2`）。
