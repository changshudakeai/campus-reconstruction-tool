## 🎯 验收标准

### 核心交付物：采集页
- [ ] 采集页 UI（`collection.slint`）：
  - 六类别清单（复用 collection.category_* 文本键），每类别显示采集状态与"可跳过"标注

- [ ] 采集完成后方案卡片进度推进为"下一步：评审"

### 核心交付物：A1 完整采集操作入口（吸收 T16 移交债务①）
- [ ] 采集页底部常驻"查看采集报告"入口（audit.report_entry 文本键 + F7 AuditReportView）
- [ ] S1 对“开始采集”只调用 A1；A1 完成采集、保存、B14 候选几何处理和覆盖体检：
  - 无疑点 → 静默通过，不打扰
  - 有疑点 → 全部合并为一个 B7 error 级模态弹窗（禁横幅），问句措辞
  - 点"知道了"→ 裁决按方案记住，重开不再弹，仅重新采集后重评估
- [ ] 采集报告视图可查历史体检结果与各类别数量汇总
- [ ] A1 按 ADR-0040 发布完整候选批次：报告同时给出原始观测、可评审、自动修复、已隔离数量；半截批次不得解锁评审
- [ ] 高德 POI 点位只作为原始证据，不得伪造建筑轮廓；“十来栋楼”验收使用真实提供轮廓的生产数据源，自动化测试可使用明确标注的几何夹具
