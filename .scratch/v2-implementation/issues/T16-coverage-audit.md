# T16 — F7 覆盖率审计（安静哨兵 + 两条疑点规则）

**What to build:** 采集后默默体检，只在有疑点时弹一个合并窗口（点"知道了"后进评审）；禁用横幅；疑点只有两条纯统计规则（空类别、其他占比超阈值），报告措辞一律问句。

- **窗口契约**：无专门缝，F7 独立运行并调用 B7 通知中心呈现疑点窗口。
- **业务规则**：两条疑点规则——① 采集过但 0 项的空类别；② "其他"占比超阈值（默认 20%）；跳过的类别不算疑点标注"未采集（跳过）"；疑点关闭后记住裁决仅重新采集后重新评估。
- **常驻入口**："采集报告"入口可查历史体检结果。

**Blocked by:** T01, T02（crate 框架）, T03（文本外置用于报告措辞）, T13（F4 采集数据是体检输入）, T15（B7 弹窗 API）

**Status:** completed (2026-07-26, commit c9430e0)
