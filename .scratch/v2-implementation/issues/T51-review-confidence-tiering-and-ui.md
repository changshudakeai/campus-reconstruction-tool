# T51 — 评审工作台：置信度分档与评审流程/UI 优化

**Status:** ready-for-agent（2026-08-18，产品负责人访谈确认）

**What to build:** 把评审台的筛选/排序改为“置信度”分档（高/中/低），理顺
“应用建议 → 人工批量 → 封账”的操作顺序，修复筛选刷新、分页消失与滚动卡顿，
删除暂停/继续评审按钮，并让一键应用建议成为显眼的主操作。

## 已确认的产品决策（2026-08-18 访谈）

1. **置信度分档（高/中/低）**：由现有轻量建议规则映射，不引入数值评分。
   - 高＝名称清晰＋形状完整＋无异常（建议保留）；
   - 中＝存在不确定信号、需人工确认；
   - 低＝未命名/重复嫌疑/重叠/修复过等需关注。
   卡片保留动作标签与理由（建议保留/建议人工确认/建议剔除＋原因）。
2. **筛选芯片**：原 5 个（需要关注/未命名/建议保留/建议人工确认/建议剔除）
   改为 4 个：全部/高/中/低；候选列表按 高→中→低 排序；地图标注/加载按同序
   优先高置信。
3. **一键应用建议**：只把 高置信 → 保留，不剔除任何候选；保留确认弹窗（显示
   将变更数量与理由分布）；按钮放明显位置并用颜色标注，防止用户错过。
4. **批量操作**：移除“选中 2 张才弹选项卡”与“批量剔除 ≥5 才确认”的门槛；
   候选卡片上方固定一行（不随滚动消失）：全选复选框（只选当前页）＋已选数量＋
   批量按钮（改为保留/改为剔除/改为待定）；批量剔除保留一次确认。
5. **删除“暂停评审/继续评审”按钮**（自动检查点已覆盖；离开自动保存、回来
   自动恢复，无需手动暂停/继续）。
6. **分页**：筛选后分页保持可用，页码行始终显示（含 1/1），不再因只剩一页而
   消失。
7. **滚动卡顿修复**（实现方式由实施者决定，如分页大小/渲染优化）。

## 缺陷/问题（真机观察，需复现根因）

- 筛选芯片选中后，候选卡片不按对应筛选刷新（workbench 层筛选逻辑存在且有测试，
  疑为 UI 模型同步/当前页切片刷新问题）。
- 候选卡片滚轮滑动卡顿（帧率低）。
- 筛选后分页控件消失（`review.slint` 中 `if page-total > 1` 隐藏分页行）。
- 多选时只有第一张候选卡片底色变蓝：`review.slint` 把蓝色底色绑在
  `card.highlighted`（地图高亮，单张）而非 `card.selected`（多选状态）；
  选中底色应与多选状态一致，地图高亮保留独立样式（如描边），两者解耦。
