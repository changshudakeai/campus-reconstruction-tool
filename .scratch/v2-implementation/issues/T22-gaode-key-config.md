# T22 — 高德密钥配置进设置页（F1）

> 法源声明：与工单描述冲突时以 ADR 为准。重点条款：ADR-0004（应用级全局设置）、
> ADR-0021（要紧错误必须弹窗，禁止横幅）、ADR-0005（文本外置）、ADR-0017
> （F1 / B2 模块边界，存储只经 B2 公开 trait）。
> 密钥纪律：第三方服务密钥必须经 F1 全局设置统一管理，禁止硬编码进代码或
> 明文入 git。
> 规格来源：`.scratch/v2-implementation/PRD-gaode-map-integration.md`。

**What to build（负责人视角）：**
负责人在设置页看到"高德地图密钥"分组：两个输入框（key、安全密钥）可录入、
保存、修改，重启应用后仍在；旁边有"测试连通性"按钮，点一下就知道 key 通不通
——通了就提示成功，不通就弹窗说清原因。没配 key 就打开需要地图的页面
（屏 4、校区搜索）时，程序弹窗引导去设置页，不静默失败、不显示空白地图。
密钥存进数据库设置表（本机明文存储——高德安全密钥本就设计给浏览器前端可见
场景；DPAPI 加密列为后续增强）。demo 临时密钥文件在本单落地后删除。

**Blocked by：** 无——可与 T21 并行。

**Status：** completed（2026-07-28 commit 790af79 REDO：高德 Key 配置 UI 落地）

## 验收标准

- [ ] 设置页"高德地图密钥"分组：key + 安全密钥两字段可录入、保存、修改，
  重启后仍在（经 B2 设置表持久化）
- [ ] "测试连通性"：正确 key → 成功提示；故意填错 → B7 模态弹窗 + 公告栏
  留底（ADR-0021），全程无横幅通知
- [ ] 空 key 进入屏 4 / 校区搜索 → 模态弹窗引导去设置页；不显示空白地图、
  不静默失败

  无任何 key 硬编码
- [ ] B2 仅经公开 trait 扩展两个设置键，F1 不触碰 SQL（ADR-0017）
