# T24 — 屏 4 圈边界搬上真地图（OSM 自动获取 + 人工调整）

> 法源声明：与工单描述冲突时以 ADR 为准。重点条款：**ADR-0029（边界来源：
> OSM 自动获取优先、人工调整、人工圈画兜底、无候选列表）**、ADR-0007（边界
> 属于方案）、ADR-0008（画边界从校区锚点开始）、ADR-0012（必经第一步）、
> ADR-0027（五步步骤条）、ADR-0017（壳零业务逻辑）、ADR-0021（弹窗铁律）、
> ADR-0005 / ADR-0023（文本外置、零色号）。
> 规格来源：`.scratch/v2-implementation/PRD-gaode-map-integration.md`；
> v1.x 查询逻辑参考：`New branch/native/crates/campus-services/src/public_source_v1.rs`。

**What to build（负责人视角）：**
负责人打开屏 4 第①步，看到以校区锚点为中心的真高德地图嵌在界面里；
程序自动查询 OSM，把校区边界多边形直接画在地图上；边界不准就在地图上
拖动顶点调整，调完确认，第①格打勾、第②格解锁、方案卡片进度同步。
断网或 OSM 没有该校边界数据时，提示后转为手动在地图上逐点圈画
（撤销/清空/确认沿用现有交互）。边界点以经纬度交给 B5 保管。

**Blocked by：** T21 ✅（嵌入探针）、T22 ✅（密钥配置）、T23 ✅（取点协议）

**Status：** completed（2026-07-28 commits ae32aee/27cefea/f4972ff：OSM 自动边界+顶点编辑）

## 验收标准

- [ ] 屏 4 第①步显示嵌入的真高德地图（原 `boundary.map_placeholder` 画布
  区域），初始中心 = 校区锚点（ADR-0008），全程单窗口不弹出
- [ ] 进入第①步自动触发 Overpass 查询（锚点 + 合理半径，
  `amenity~university|college|school` 的 way/relation，参考 v1.x
  boundary_query）
- [ ] 返回多个对象时**自动选取最匹配一条**（排序：包含锚点 → 校区名称
  匹配 → 锚点距离最近；Rust 侧实现、可单测），**无候选列表 UI**（ADR-0029）
- [ ] 边界经 WGS-84 → GCJ-02 转换（`AMap.convertFrom`）后绘制为地图
  多边形，肉眼无偏移
- [ ] 顶点可拖拽调整（高德多边形编辑插件），调整后坐标实时回传 Rust
- [ ] 查询失败 / 无数据 → 按 ADR-0021 分级提示 → 自动切换人工圈画模式
  （点击地图落控制点 + 实时连线预览；撤销/清空/确认沿用现有交互）
- [ ] 确认边界经 B5 校验（自相交 / 点数不足 → B7 弹窗，不闪退）；
  边界点以经纬度存入 B5（壳→B5 既有缝；ADR-0007）；壳内无业务计算
- [ ] 步骤条打勾 / 解锁与方案卡片文案联动（per-plan 单一事实来源，
  ADR-0007）；屏 4 文字重叠清零
- [ ] 随屏切换：离开屏 4 隐藏 WebView，返回恢复显示
- [ ] 破坏性测试全过：快速连点、拖动窗口过程中操作、断网加载（回退人工
  圈画而非空白）、窗口最大化 / 还原、画自相交形状点确认（弹报错非闪退）
- [ ] 单测：排序选取规则（含锚点/名称/距离优先级）、经纬度 → 平面米 →
  MC 块链式换算、自相交检测、扩展后的 IPC 协议解析
