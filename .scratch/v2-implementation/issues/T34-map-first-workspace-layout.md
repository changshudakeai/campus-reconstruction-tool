# T34 五步工作区"地图为主 + 左侧抽屉"布局改造（做法 A：地图让位）

Status: completed（2026-08-17 发布收口）
Blocked by: 无（T33 评审滚动修复与本工单互不阻塞；本工单不改评审页）

## What to build（负责人视角）

五步工作区改为"地图为主、抽屉为辅"：

- 顶部五步条不变（圈边界 → 定朝向 → 采集 → 评审 → 导出），常驻。
- 地图尽量填满五步条以下的画面；圈边界、定朝向直接在地图上操作。
- 左侧边缘有收拉箭头：点击展开抽屉，再点收回。抽屉展开时地图往右让位
  （做法 A），关闭时地图恢复原宽。
- 抽屉内容按步骤：
  - ① 圈边界：当前点数、撤销、清空、确认边界（地图内的 HTML 工具栏按钮
    迁入抽屉，地图退化为纯画布 + 消息桥）。
  - ② 定朝向：自动算出的角度、小罗盘预览、手动输角度、重置、确认。
  - ③ 采集：来源/开始采集/进度/差异摘要/查看报告。
  - ⑤ 导出：开始导出、结果/错误状态。
- 朝向页删除"两点/角度"两个模式切换：默认就是地图上点两个点；手动输度数
  收进抽屉，后改覆盖先改，并明确提示"将按新值重算朝向、影响导出"（沿用
  现有 F5 重算规则）。

## 缺陷事实（现状）

- 地图是原生子窗口、硬编码坐标叠在 Slint 画面之上，与文本/按钮框架互相
  遮挡：`main.slint` 遗留重复状态文字（y:470）和重复按钮（y:500）落在地图
  矩形内；朝向页提示文字（y:64）压住画布上缘（y:56）；Slint 模态弹窗会被
  地图盖住。
- 朝向页"两点/角度"两个模式切换与页内罗盘、输入框、提示叠放，用户无法理解。
- 地图内 HTML 工具栏与 Slint 框架按钮功能重复，是 T31-D6/T32 两轮 bug 的来源。

## 范围

1. 只改工作区（screen 4）内步骤 ①②③⑤ 的布局与交互落点；步骤 ④ 评审保持
   现状整页，本工单不并入抽屉、不改滚动/封账逻辑。
2. 地图交互语义不变：边界点画/OSM 自动获取、朝向两点/度数、采集、导出全部
   沿用现有功能入口与 IPC；S1 仍只呈现与转发（ADR-0037），业务规则不变
   （边界唯一必填 ADR-0041、朝向可选默认正北、采集/评审可跳过）。
3. 删除：`main.slint` 遗留重复状态文字与按钮；朝向页两个模式切换、页内画布
   占位/罗盘/输入框（功能迁入抽屉）；地图 HTML 工具栏按钮（或停用）。抽屉
   文字全部走 `zh-CN.json`（ADR-0005），颜色走 Theme（ADR-0023）。
4. 弹窗遮挡统一处理：把 T33 未提交的"错误弹窗前隐藏地图"补丁扩展为统一
   机制，覆盖错误/确认/输入弹窗；关闭后恢复地图时必须记住当前步骤模式
   （边界页 vs 朝向页），不得恢复错页。
5. 地图矩形与抽屉开合联动：抽屉宽约 280–320 逻辑像素（执行时可微调），开合
   后地图 `set_bounds` 跟随；不再硬编码地图坐标，改为由 Slint 布局槽位上报
   真实矩形。
6. 不改产品基线、不开 GitHub Issues；本次布局是对 ADR-0027"主区域整屏显示
   当前步骤"的呈现细化（负责人已确认），如需可补一行 ADR 记录。

## 验收标准（逐条证据）

1. 步骤 ①②③⑤ 均为"顶部五步条 + 地图主画面 + 左侧抽屉"；抽屉开合时地图
   让位/恢复，无闪烁、无遮挡（截图 + UIA 矩形断言：地图矩形与五步条、抽屉、
   按钮互不相交）。
2. 圈边界：地图点画与 OSM 自动获取正常，撤销/清空/确认经抽屉按钮完成并反馈
   状态；地图内不再出现 HTML 工具栏按钮。
3. 定朝向：地图点两点 → 参考线 + 角度反馈到抽屉；手动输度数覆盖并提示重算
   影响；页内无模式切换、无重叠元素。
4. 采集/导出：抽屉内完成开始/进度/结果/失败提示；失败不产生伪成功产物。
5. 模态弹窗（错误/确认/输入）在地图步骤弹出时可见可点；关闭后地图恢复且模式
   不丢。
6. 800×666、1000×666、125% DPI 下 1–5 无回归；步骤 ④ 评审页与现状一致。
7. 全部门禁全绿（Windows：`SLINT_BACKEND=software`、`CARGO_BUILD_JOBS=2`）：
   workspace tests / xtask ci / clippy `-D warnings` / fmt / machete / deny /
   timings；新增或更新的定向契约测试覆盖抽屉开合、地图矩形、朝向输入覆盖、
   弹窗遮挡。
8. 重建便携包并更新人工验收记录。
