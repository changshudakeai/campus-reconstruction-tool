# T19B-7 — 评审工作台（F5）

**Status:** historical（2026-08-17 v2.0.0 发布收口；不具独立开工权）

**What to build**: 贯穿弹剧本的"评审一条"环节——三栏布局评审台，候选卡片三态管理（保留/剔除/待定），批量操作与确认闸，评审状态即时生效。

- **窗口契约**: 缝 4（评审 ↔ 存储，零写库：评审过程纯内存状态机，终态经 F5 批量写回）；缝 5（封账闸门 SealGate 由 F9 触发，本单只保证 F5 侧接口就绪）
- **业务规则**: 三态评审（T06）：待定灰色、保留/剔除立即生效不卡顿；批量剔除 ≥5 项二次确认闸；暂停/恢复评审
- **UI 决策法源**: ADR-0027（五步步骤条：评审占第四格；跳转规则）+ ADR-0028（教程三泡，本单新增 review_intro 钩子）；与本单描述冲突时以 ADR 为准

**Blocked by**: T19B-6（有采集数据才有候选可评审）

**Status**: ready-for-agent

## 🎯 验收标准

### 核心交付物
- [ ] 评审台 UI（`review_workbench.slint`）三栏布局：
  - 左栏：候选列表（类别筛选 + 三态状态色标）
  - 中栏：选中候选详情（类别、标签与属性，复用 review.info_category / info_tags）
  - 右栏：操作区（保留/剔除/待定按钮 + 全选/取消全选 + 批量操作）
- [ ] 三态交互（全部复用 F5 ReviewWorkbench 已有状态机，壳零业务逻辑）：
  - 单条：点击即改状态、立即生效不卡顿
  - 批量剔除 ≥5 项 → 二次确认弹窗（review.batch_reject_confirm_*）
  - 计数条：X 项候选 / 已选 X 项 / 待定 X 项（复用 review.*_count）
- [ ] 暂停/恢复评审（review.pause / resume，临时状态落盘由 F5 负责）
- [ ] 评审有进展后方案卡片进度推进为“下一步：导出”

### 教程钩子（债务③-3，按 ADR-0028 重排至本单）
- [ ] F2 “review_intro”钩子：首次进入评审步骤页时调用 F2 钩子接口，弹“每条候选给个态度：要、不要、再想想”气泡（坐标占位，定稿归 T19B-8；提示点枚举调整已在 T19B-5 完成，本单只埋钩子）

### 文案与国际化
